# 自定义题库刷题 App

[![CI](https://github.com/lytree/fenbi/actions/workflows/ci.yml/badge.svg)](https://github.com/lytree/fenbi/actions/workflows/ci.yml)
[![Release](https://github.com/lytree/fenbi/actions/workflows/release.yml/badge.svg)](https://github.com/lytree/fenbi/actions/workflows/release.yml)

一个可以**导入自己的题库**并刷题的 Android 应用。支持 `JSON` / `CSV` / `Excel(.xlsx)` / `TXT` / `ZIP 题库包`
五种导入格式，自动探测格式与编码。**一个导入文件就是一份试卷**，导入后直接开练：限时答题、手写标注、查看成绩报告。

## 功能

**导入**

* 五种格式：`JSON` / `CSV` / `Excel(.xlsx)` / `TXT` / `ZIP 题库包`，自动探测格式、自动识别编码（UTF-8 / GBK）
* **从链接导入**：粘贴 `http/https` 下载链接，App 内下载后直接进预览，解析、勾选、建卷与本地文件完全一致（支持跳转与 `Content-Disposition` 文件名）
* 表头别名自动映射（`题干` / `题目` / `stem` / `question` … 都认），全半角、空格、下划线一并归一
* 导入校验：逐行规范化 + 错误/警告清单，定位到行号，勾选后再生成试卷
* **答案可选**：导入时一个开关决定「同时导入答案」还是「只要题目」——题库里那份答案不想要也能直接关掉
* **答案可后补**：缺答案的题按「待补答案」正常导入，做完再补——**逐题手填**（不用准备文件，支持批量粘贴）或导入一份答案文件，按已有作答直接重判
* **题库包**：`qbank.json` + `images/` 打成 zip，材料配图随包走，换设备不丢图

**词库（成语 + 实词）**

* **一个词库 Tab**：成语和实词同表存放，按**拼音首字母**分组（A→Z，右侧字母条点击跳组），分类胶囊一键筛「全部 / 成语 / 实词」
* **标签筛选**：细分标签（名词 / 动词 / 褒义 / 对比辨析 / 各语义分组）走弹窗多选，带搜索与条数，多标签取并集、与分类取交集；已选标签单独一行，点一下就能去掉
* **不再只收成语**：以前只认四字成语、其余丢掉；现在实词一并导入，只丢真正没法用的行（空、不含汉字、长到像整句），每条的跳过原因都标到行号
* **直接导文档**：Word(`.docx`) / Excel(`.xlsx`) / CSV / TXT / JSON 五选一，文档里有表格就按表头取列，没有表格就一段一个词条；表头别名（`词条` / `词语` / `成语` / `word` …）自动认
* **分类自带**：源表有「分类」列就用它（还支持细分：名词 / 动词 / 褒义…）；没有就按字数推测（4 字记成语、其余记实词），推测了多少条会在导入页标出来，**不静默丢词**
* **拼音不用手填**：表里有「拼音」就自动去声调使用，没有就按内置 2.7 万字拼音表逐字拼；首字母入库即算好，排序固定口径 `首字母 → 全拼 → 词条`
* **装上有词**：内置《成语与实词汇总（合并版）》**2201 条**（成语 1075 · 实词 1126），首次打开词库 Tab 自动灌入，只灌一次；想重灌进导入页选「内置词库」
* **重复导入按词条合并**，也可以勾「覆盖整个词库」整表换版本

**答题**

* 单题 / 多题双模式：一屏一题（左右滑动）↔ 连续滚动列表，切换时按当前题双向定位
* **卷面三级结构**：大类题型 → 材料 → 题目。题号按卷面顺序**全卷连续**（1,2,3…），单题模式的答题内容以材料为准分页（每个大类一页说明 + 每个材料组一页）；答题卡分组、弹出材料、左右分屏共用同一份结构
* **材料题组上下分栏**：同一则材料带多道小题时（资料分析一类），单题模式下整组放同一页——材料固定在上区独立滚动，小题放底部**悬浮面板**（圆角 + 投影）独立滚动，中间手柄上下拖动调节占比（20%～80%，记忆偏好），做题时材料始终在屏
* 计时交卷：倒计时、剩 5 分钟提醒、超时自动交卷、未答题二次确认
* 夜间模式：答题流程全套换色，偏好持久化
* 标记、笔记、答题卡、字号调节

**标注**

* 题目遮盖层：手写 / 触控笔直接写，压感笔迹，写字时不会误点选项、不会翻页
* 四档遮盖（关 / 浅 / 中 / 深），贴屏幕右边缘拖动可滚动题目，笔迹跟着文字走
* **笔迹钉在题目 / 材料上**：滚动、切浏览模式、交卷出解析都不跑位；跟随本次作答记录存库（每题只留最新一份，可撤销），退出重进还在，回头能接着补一笔
* **材料与题目分开标注**：材料块上的圈画单独锚定、单独存储，不按题干定位，换版式也不偏移
* **五色笔迹**：红 / 蓝 / 绿 / 橙 / 黑，设置页「手写标注」里选默认色，写画工具条的色点也能随手换
* 资料分析左右分屏：左材料右题目，两栏都能标注

**材料**

* Markdown 表格渲染成真表格，列宽按内容自适应整屏宽度，不会截掉右列
* 配图支持本地路径 / `file://` / `content://` / `asset://` / base64，点一下整屏看大图
* 没有配图时可用 `:::chart` 写数据让 App 自绘折线 / 柱状图
* **材料整块展示（对齐参考应用）**：材料在题目卡顶部通栏排布，白底、不加内嵌灰卡片，随卷面一起滚动；同一则材料带多道小题时**只在第一题出现一次**，后面的题接着往下排
* 「弹出材料」半屏浮层（手机端）：从底部弹出约 65% 屏高，材料独立滚动，A- / A+ 调字号；平板端保持就地左右分屏

**复盘**

* 成绩报告：得分 / 正确率 / 用时 / 逐题解析，四态标色（全对 / 部分得分 / 错误 / 未答）
* **补答案重判**：整卷没答案也能先做——交卷后「补答案 → 逐题补录」逐题填（或导入答案文件），报告立刻按你的作答重判
* 判题规则可配：多选少选给分、不定项少选 50%、填空部分给分、主观关键词命中给分

**成语**

* 入口在词库页顶部「词库 / 成语」切换（底部导航固定 5 项，成语汇总不单独占 Tab）
* 内置「成语汇总」词典（1075 条释义）：按拼音首字母 A-Z 分组，右侧字母索引一键跳转
* 搜索框同时匹配成语 / 释义 / 归类名，输入单个字母即按首字母筛选
* 文档末尾的「成语归类表」以两级标签呈现（大类 → 子类），点标签即筛选；条目上的归类标签也能反向筛选
* 释义默认两行，点条目展开 / 收起全文

**考点背诵**

* 题库页右上角「考点背诵」进入：内置 **1110 条考点**（更新于 2026-10-29），其中 **超格《2027 政治理论背诵手册》「核心知识带背」全套 18 节 1024 条**（新思想 + 时政理论，按课程分 18 个分类），另含精编政治理论考点 86 条（四中全会·十五五、2026 两会·经济、建党 105 周年、新思想、党的基本知识、马原、毛中特、史纲、思修与法治）
* 「选择考点范围」弹层按 **超格 · 新思想（9 节）/ 超格 · 时政理论（9 节）/ 精编考点（9 类）** 二级分组展示；点分组标题可一次性背整组，点课程可只背单节
* 分组可自定义：右下「＋ 新建分组」建分组，**长按课程**把它移到别的分组，分组右侧「⋯」可重命名 / 删除（删除后组内课程落到「未分组」，考点不丢）；改动存本地，升级不丢
* 超格内容由 `tools/build_recite_asset.py` 从抓取的课程文本整理生成，可重复运行以更新（见脚本内说明）
* 填空式背诵卡：轻点卡片显示 / 收起答案；「未掌握 / 已掌握」两档计数实时更新
* 「换一个」顺序下一条、「随机」抽一条、「记住了」归档到已掌握（已掌握里可「取消掌握」退回）
* 星星标重点，目录里可按分类或「只看重点」集中复习；顶栏 A小/A中/A大调字号，详情弹窗看记忆提示与来源
* 掌握状态、重点、字号、筛选范围全部本地持久化，退出重进仍在

> 当前版本答题流程只完整支持**选择题**（单选 / 多选 / 不定项 / 判断）。填空、主观题在数据层保留，
> 导入时会被拒绝或降级，详见 [格式规范](docs/02-题库格式规范.md#只支持选择题的原因)。

## 三步导入

* **题库导入**：`JSON` / `CSV` / `Excel(.xlsx)` / `TXT` 四种格式，自动探测格式、自动识别编码（UTF-8 / GBK）、表头别名自动映射；也可以「从链接导入」，粘贴下载链接直接下载预览
* **答案可后补**：试卷常常只有题目没有答案。缺答案的题按「待补答案」正常导入、正常答题，做完之后再补：成绩报告里「补答案 → 逐题补录」直接在 App 里一道道填（支持批量粘贴 `1.A 2.B`），或者导一份答案文件（`题号,答案` 表格或题库答案版），按题号 / 题干自动匹配，**按已有作答直接重判**，不用重做一遍
* **导入校验**：逐行规范化 + 错误/警告清单（定位到行号），可勾选后再生成试卷
* **题库管理**：多题库、题目列表、知识点/地区/难度/来源标签
* **导入即建卷**：每个导入的文件直接生成一份试卷，题目按文件顺序整卷入卷；不再随机抽题组卷，同名试卷可覆盖导入
* **答题页**：顶部关闭 / 计时胶囊 / 铅笔 / 书签 / 更多图标区，**整页白底通铺的连续卷面**（题目不再是独立圆角卡片，题与题之间只隔一条 0.5dp 细线），浅蓝题型标签，圆形 A/B/C/D 选项徽标（选中变蓝色实心圆），右侧「细线星 / 笔 / 星」三图标（标记 / 写画 / 收藏）
* **模块说明卡**：按 `subject` 自动聚合，同一模块只在首题上方出现一次——浅蓝渐变圆角块 + 「资料分析 (5题)」+ 该模块的作答说明（资料分析 / 数量 / 言语 / 判断 / 常识各一套文案）；没填 `subject` 的题库不渲染，不会硬塞空标题
* **单题 / 多题切换**：`更多 → 多题浏览 / 单题浏览`。多题为连续滚动列表，单题为一屏一题（左右滑动切题，长题干可在页内纵向滚动），**一则材料对应的多道小题在单题模式下整组占一页——材料在上、小题悬浮在下，拖中间手柄调上下占比**；两套容器共享同一份题目卡渲染，切换时按「当前正在看的题」双向定位，答案、标记、收藏、字号、交卷后的解析全部同步；选择会持久化，下次进入沿用
* **夜间模式**：`更多 → 夜间`。覆盖答题页全套元素（题目卡、题型标签、选项徽标、材料表格、解析）、更多面板、手写工具条、答题卡弹层与系统状态栏／导航栏；偏好持久化，重进直接生效
* **横向滑动切题**：`ViewPager2` 左右滑动翻页；写画模式下遮盖层会拦掉翻页与选项点击，点「完成」退出后立刻恢复
* **题目遮盖层（可写）**：点题目卡右上角那支**笔**（或 `更多 → 手写标注·遮盖`），题目区盖上一张半透明薄纸——**手指或触控笔都能直接写**，带压感笔迹粗细。这一层会吞掉全部触摸：写字时不会误点选项、不会把题翻过去，掌托 / 第二根手指落下也不打断笔迹。想往下看长题干时，**贴着屏幕最右边那一条上下拖就能滚**（不落笔，笔迹跟着文字一起走；分屏页左边缘还有一条专门滚材料）。悬浮工具条提供撤销 / 清空 / **笔色**（色点循环换色）/ **遮盖档位（关·浅·中·深）** / 标记 / 完成；点「完成」只是退出写画模式，**笔迹留在原处**，可以接着选答案。笔迹跟随本次作答记录落库（每笔各带颜色，同一题 / 同一份材料只留最新一份，可撤销），**钉在题目卡或材料块上**——滚动、切换多题/单题浏览、交卷后出解析都不会跑位，退出重进、回头补标也照样在；笔迹配色在设置的「手写标注」里统一指定
* **资料分析左右分屏**：「更多 → 开启左右分屏」进入分屏页——左栏材料（约 40% 宽，表格按栏宽自适应缩放字号），右栏该材料对应的全部题目连续排布；两栏都能用遮盖层做标注；中间手柄可拖动调节左右占比（25%～75%，记忆到偏好）
* **材料配图与弹出材料**：图谱类材料（折线图 / 柱状图 / 饼图）**直接显示图片**——材料里写 `![说明](路径)` 就行，支持本地路径、`file://`、`content://`、`asset://` 与 base64，按材料宽度铺满、点一下整屏看大图；没有配图的纯文本题库也可以用 `:::chart` 写数据让 App 自绘。材料卡右上角「弹出材料」：平板进就地分屏、手机进**底部半屏浮层**（材料独立滚动，A- / A+ 调字号），都不打断答题状态
* **弹出材料左右分屏（平板端，一则材料多个题目）**：对齐参考应用——平板（最小屏宽 ≥ 600dp）上材料组点「弹出材料」，**当前答题页就地分成左右两栏**：左栏材料（表格 / 图表同套渲染，可「收起材料」还原），右栏这组题目连续排布（往下就是下一题）、照常作答、实时同步主容器，且右栏题卡**不再重复渲染材料**（左栏已有整栏）；左栏头部显示组内进度（N/M）。**手机端**保持常规：点「弹出材料」进底部半屏浮层，题目卡里材料原样保留
* **标记与笔记**：书签图标标记本题，「更多 → 编辑笔记」写思路，笔记按题保存
* **计时与交卷**：倒计时、剩 5 分钟提醒、超时自动交卷、交卷二次确认（"你还有 N 道题目未作答，确定交卷吗？"）
* **练习模式（即时判分）**：`更多 → 练习模式·即时判分`。开启后作答立刻判色——正确项绿实心、选错项红实心，解析内联展开，不必等整卷交卷（对齐参考应用「练习」作答口径）；选项统一竖排一列（与参考应用手机端一致）
* **中途退出续做**：退出自动保存作答 / 标记 / 已用时，重进弹「继续答题 / 重新开始」，倒计时从上次退出的地方接续；交卷后进度自动清除
* **收藏持久化**：星星收藏落库，跨会话保留，重进 / 重装升级都不丢
* **成绩报告**：得分 / 正确率 / 用时 / 逐题解析，四态标色（全对 / 部分得分 / 错误 / 未答）；多模块卷自动汇总**分模块正确率**（按科目 / 知识点聚合），定位薄弱模块
* **错题重练**：成绩报告右上角一键把本次答错 / 部分得分的题按原顺序生成新卷，直接开练
* **判题规则可配**：多选少选是否给分、不定项少选给 50%、填空漏填给部分分、主观题关键词命中给部分分、判断题兼容"对/错/√/×/T/F"

## 目录

```
app/            Android 工程（Kotlin + 原生 View + ViewBinding）
docs/           文档与配图（images/）
sample/         有内容的完整示例（11 题四种同源格式、资料分析题库包）
templates/      可直接导入的空模板 + 生成脚本
```

`sample/` 与 `templates/` 都由一份 JSON 单一数据源生成：

```bash
node sample/make_xlsx.js        # 改 sample/行测基础示例.json 后重跑，生成 csv / txt / xlsx
node templates/make_templates.js # 重新生成模板并回读校验
python sample/make_package.py   # 生成题库包目录与 zip
```

## 构建

需要 JDK 21、Android SDK platform 35；用仓库自带 wrapper：

```bash
export JAVA_HOME=/path/to/jdk-21
export ANDROID_HOME=/path/to/android-sdk

./gradlew assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

> `gradle.properties` 里的 `org.gradle.java.home` 是作者本机路径，换机器记得改。
> 环境细节与测试见 [06 构建与测试](docs/06-构建与测试.md)。

CI 用 GitHub Actions 跑：推送 `main` 或提 PR 自动编译 debug 包（产物在 Actions 里下载）；
推送 `v*` tag 自动出 release 包并发 Release，签名密钥从 Secrets 读，没配就用 debug 签名。

```bash
git tag v1.0.1 && git push origin v1.0.1   # 触发发版构建
```

细节见 [06 构建与测试 § CI](docs/06-构建与测试.md#ci-github-actions)。
