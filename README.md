# 自定义试卷刷题 App

一个可以**导入自己的试卷**并刷题的 Android 应用。导入统一只认 **Excel（.xlsx）**，
图片随**试卷包（zip：试卷.xlsx + images/）**一起导入。一次导入 = 一个标题，
一个工作表 = 一份试卷，列表按「标题 → 试卷 → 题目」树形展开。导入后直接开练：
限时答题、手写标注、查看成绩报告。

## 功能一览

从导入、答题到复盘、备份的完整刷题闭环，另带词库 / 政治 / 常识背诵与电脑端 AI 协作：

| 功能 | 说明 | 细节 |
|---|---|---|
| 导入 | 统一 Excel（.xlsx），表头别名自动识别；多文件、多工作表一次建卷；支持从下载链接导入；逐行校验定位到行号 | [02](docs/02-试卷格式规范.md) |
| 答案可后补 | 没答案的卷子照常导入和作答，做完后逐题补录（支持批量粘贴）或导入答案文件，按已有作答自动重判 | [04](docs/04-答案后补.md) |
| 试卷包 | `试卷.xlsx` + `images/` 打成 zip，图片随包走 | [03](docs/03-试卷包.md) |
| 答题 | 单题 / 多题双模式、倒计时交卷、材料题组分栏与左右分屏、选项带图、长按排除选项、练习模式即时判分、中途退出续做 | [01](docs/01-快速开始.md) |
| 手写标注 | 手指 / 触控笔直接写，四档遮盖、五色笔迹，笔迹钉在题目 / 材料上不跑位 | [05](docs/05-界面与交互.md) |
| 材料 | Markdown 表格渲染真表格，支持配图与 `:::chart` 自绘图表 | [05](docs/05-界面与交互.md) |
| 复盘 | 成绩报告含全卷对错一览、分模块正确率、每题用时；一键错题重练；判题规则可配 | [01](docs/01-快速开始.md) |
| 背诵 | 内置词库（成语 1318 + 实词 1127）、政治考点 1204 条，填空式背诵卡；常识照格式填 JSON 即有内容 | [11](docs/11-背诵.md) |
| 局域网编辑器 | 手机起网页服务，同一 Wi-Fi 的电脑用浏览器直接加题改题，改完一键发布 | [12](docs/12-局域网编辑器.md) |
| MCP 接入 | AI 客户端（Claude Desktop / Cursor）可直连手机题库，列组、加题、改题、批改 | [13](docs/13-MCP接入.md) |
| 备份 | 一键整库备份为 zip，走系统分享存任意网盘；可选 WebDAV 每日自动备份；换机整份恢复，失败可回滚 | [10](docs/10-备份与恢复.md) |

> 当前版本完整支持**选择题**（单选 / 多选 / 不定项 / 判断）；填空、主观题会被拒绝或降级，
> 详见 [格式规范](docs/02-试卷格式规范.md#只支持选择题的原因)。

## 快速开始

「试卷」页 → 右上角「导入」→ 选文件（或粘贴下载链接、先「载入示例」跑一遍）→ 勾选导入，直接生成试卷。
没有现成试卷就用 [templates/](templates/) 里的模板照着填。详细步骤与模板说明见 [01 快速开始](docs/01-快速开始.md)。

## 构建

需要 JDK 21、Android SDK platform 35：

```bash
./gradlew assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
```

环境配置、Release/R8、CI 发版见 [06 构建与测试](docs/06-构建与测试.md)。
