# 01 快速开始

## 一、装上去

两种方式：

| 方式 | 做法 |
|---|---|
| 直接装 APK | 拿仓库构建好的 `app-debug.apk`（或 Releases 里的包），`adb install -r app-debug.apk` |
| 自己构建 | 见 [06 构建与测试](06-构建与测试.md)，`./gradlew assembleDebug` |

最低 Android 7.0（API 24）。

## 二、导入一份题库（三步）

1. **进导入页**：底部导航切到「试卷」（首页），点右上角「导入」。
   这是全 App 唯一的导入入口：试卷直接在本页选文件，词表点卡片里的「导入词表」再走另一套流程。
   （把 `xlsx` / `zip` 从别的 App 分享过来，也会落在这里。）
2. **选文件**：点选 xlsx 直接出预览。
   也可以点「载入示例题库」，先拿内置样例跑通流程——示例不消耗文件选择器权限。
   或者点「从链接导入」，粘贴题库文件的 `http/https` 下载链接，App 下载完成后同样进预览（支持 Excel 与题库包）。
3. **看一眼预览，勾选要的题，点导入**。
   预览页会列出：格式 / 总行数 / 可导入 / 缺答案 / 警告 / 错误，以及每条问题的行号和原因。
   试卷名默认取文件名，可以改；限时留空或 0 表示不限时。

导入结果：**一个工作表 = 一份试卷**，题目按文件里的顺序整卷进卷（不随机抽题）。
文件里有几张工作表就生成几份卷子，预览页顶部可以切换查看、分别勾选。
同名试卷再导入会提示覆盖。

![导入预览](images/screenshots/01-导入预览.png)

支持的格式（统一 Excel）：

| 扩展名 | 说明 | 模板 |
|---|---|---|
| `.xlsx` | 唯一格式：一张表一行一题；**每个工作表一份试卷**，表名即卷名 | [templates/题库模板.xlsx](../templates/题库模板.xlsx)（内置「使用说明」表） |
| `.zip` | 题库包：题库.xlsx + images/（图片等媒体资源随包走） | [templates/题库包模板.zip](../templates/题库包模板.zip) |

字段怎么写见 [02 题库格式规范](02-题库格式规范.md)。

> **一个工作表就是一份试卷。** 多套题按套分表放进同一个 xlsx，一次导入全部建成卷；
> 懒得拆表就在表里加一列「试卷」按行分开。两套题想合成一份，就在同一张表里按顺序排好。

## 三、答题

从「试卷」列表点进去直接开练。答题页从上到下：

* **顶栏**：`X` 关闭 / 闹钟 + 倒计时胶囊 / 居中标题「试卷名（题数）」/ 右侧导出·交卷·答题卡·更多
* **导出（下载图标）**：把当前试卷导出成 **Excel（.xlsx）**，表头与统一模板一致，导出的文件可以直接再导入（换手机带走就用它）
* **题目卡**：浅蓝题型标签，圆形 A/B/C/D 徽标（选中变蓝色实心圆）；右上角是**标记**、**收藏**、**笔**（点=写画，长按=笔记）
* **没有底部操作条**：上一题 / 下一题交给滚动与左右滑动，跳题用答题卡

> 计时：胶囊常驻倒计时，剩 5 分钟提醒，超时自动交卷。

「更多」面板里的常用项：

| 项 | 作用 |
|---|---|
| 字号 | 小 / 中 / 大，题目卡与材料一起缩放 |
| 白天 / 夜间 | 答题流程全套换深色，偏好持久化 |
| 单题浏览 / 多题浏览 | 一屏一题（左右滑动）↔ 连续滚动列表；切换时按「当前这题」双向定位（单题模式下同一则材料的连续小题合成一页） |
| 自动展示下一题 | 单选作答后自动跳下一题 |
| 手写标注·遮盖 | 给题目盖一张可写的薄纸（详见 [05 界面与交互](05-界面与交互.md)） |
| 开启左右分屏 | 本卷含材料题时出现，左边材料右边题目 |
| 导入答案（N 题待补） | 给「待补答案」的题补答案（答案文件） |
| 补录答案（手动逐题填） | 不用文件，进补录页一道道填（支持批量粘贴） |

交卷要点二次确认：还有未作答的题会提示「你还有 N 道题目未作答，确定交卷吗？」。

## 四、看成绩

交卷后进成绩报告：得分 / 正确率 / 用时 / 逐题解析，四态标色（全对 / 部分得分 / 错误 / 未答）。
「记录」页留着历次作答，点进去能回看同一份报告。

## 五、没有答案怎么办

常见情况：试卷先到手，答案后到。两条路：

1. 直接导入没有答案的卷子 —— 缺答案的题按「待补答案」入库，能正常答、正常交卷，只是暂不判分。
   文件里本来带答案、但不想用也可以：导入预览的「生成试卷」卡里把 **同时导入答案** 关掉。
2. 拿到答案后补上，**按已有作答直接重判**，不用重做：
   * **逐题补录**（推荐）：成绩报告右上角「补答案 → 逐题补录」，一道一道填进去，支持批量粘贴 `1.A 2.B`；
   * **导入答案文件**：答题页 `更多 → 导入答案`、成绩报告「补答案 → 导入答案文件」、试卷列表长按 →「导入答案」。

详见 [04 答案后补](04-答案后补.md)。

## 六、判题规则

「设置」页可调（底部「记录」页右上角齿轮进入）：多选少选是否给分、不定项少选给 50%、填空漏填给部分分、主观题关键词命中给部分分。
判断题兼容 `对/错/√/×/T/F/Y/N`。默认口径见 [02 题库格式规范 · 判题口径](02-题库格式规范.md#判题口径)。

> 当前版本答题流程只完整支持选择题（单选 / 多选 / 不定项 / 判断）。题库里的填空、主观题会在导入时被拒绝或降级为单选题，见 [02](02-题库格式规范.md#只支持选择题的原因)。
