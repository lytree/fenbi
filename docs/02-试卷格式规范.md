# 02 试卷格式规范

导入统一只认 **Excel（.xlsx）** 一种格式，走一套字段模型：**先映射表头，再逐行规范化，最后校验**。
表头写对就成；图片等多媒体资源做成试卷包（zip = 试卷.xlsx + images/），见 [03 试卷包](03-试卷包.md)。

手边没有现成试卷时，直接下载 [templates/](../templates/) 里的模板照着填最快。

---

## 一分钟看懂

| 你手上的东西 | 怎么导 | 一句话理由 |
|---|---|---|
| Excel / WPS 表格 | `.xlsx` 原样导入 | 唯一格式，表头写好就行 |
| 材料里带图 | `.zip` 试卷包 | 试卷.xlsx + images/ 一起压包，图片随包走、换设备不丢图 |

必填只有两项：**题干**，以及**选项**（当前只支持选择题）。答案可以后补。

## 字段总表

表头（或 JSON 的 key）按下面的别名自动识别，**大小写、空格、下划线、连字符、全半角括号和冒号都会被归一化**，
例如 `题 干`、`QUESTION_TYPE`、`option_a`、`（答案）` 都能认出来。

| 规范字段 | 字段名 | 可用表头别名 |
|---|---|---|
| 题型 | `type` | 题型 / 类型 / 题目类型 / type / questionType / qtype / category |
| 题号 | `no` | 题号 / 题序 / 序号 / 顺序 / 编号 / 题目编号 / 第几题 / no / number / num / index / idx / seq / questionNo / qNo |
| 题干 | `stem` | 题干 / 题目 / 试题 / 问题 / 题目内容 / stem / question / title / content / questionContent / problem / q |
| 材料 | `material` | 材料 / 材料内容 / 背景 / 背景材料 / 资料 / material / passage / context / stem2 |
| 图片 | `images` | 图片 / 图片地址 / 配图 / 插图 / 题图 / image / images / img / pic / picture / figure / photo |
| 选项 | `options` | 选项 / 选项列表 / options / choices / optionList |
| 选项 A–H | `options.A`… | A / 选项A / A选项 / option_a / optionA / 选A；也认 `选项1`…`选项8`、`1`…`8` |
| 答案 | `answer` | 答案 / 正确答案 / 标准答案 / 参考答案 / answer / correctAnswer / rightAnswer / key / ans |
| 解析 | `analysis` | 解析 / 答案解析 / 试题解析 / 说明 / 备注 / analysis / explanation / explain / remark / note / solution |
| 知识点 | `knowledge` | 知识点 / 考点 / 知识点标签 / 标签 / knowledge / point / tag / knowledgePoint |
| 难度 | `difficulty` | 难度 / 难度等级 / difficulty / level / hard / stars |
| 地区 | `region` | 地区 / 省份 / 城市 / 地域 / region / area / province |
| 科目 | `subject` | 科目 / 学科 / 分类 / 模块 / subject / category / module / section |
| 来源 | `source` | 来源 / 出处 / 试卷来源 / source / from / origin |
| 年份 | `year` | 年份 / 年度 / year / date / yr |
| 分值 | `score` | 分值 / 分 / 分数 / 每题分值 / score / points / value / mark |
| 得分点 | `keywords` | 得分点 / 关键词 / 采分点 / keywords / keyPoints / scoringPoints |
| 试卷 | `paper` | 试卷 / 试卷名 / 试卷名称 / 卷名 / 卷子 / 套卷 / 题卷 / 卷号 / paper / examName / testName（只用于拆卷，不入库） |

几条映射规则：

* **一列只能对应一个字段**，同一个字段出现两次时只取靠前的那列；
* 找不到题干列 → 整份文件直接报错（`未找到「题干/题目/stem」列`）；
* 识别不出的列会被忽略，不影响导入。

难度可写 `1/2/3` 或 `易/中/难`（也认 `简单`、`中等`、`困难`），留空或写 0 表示未标注。
分值留空时按题型给默认值：单选 / 判断 / 填空 1 分，多选 / 不定项 2 分，主观 10 分。

## 卷面结构：科目 → 材料 → 题目

导入是「一题一行」平铺进来的，卷面上的三级结构完全由 `科目` 和 `材料` 这两列的**连续重复**派生，
不另建结构表（见 [08-试卷三级结构设计](08-试卷三级结构设计.md)）：

| 级 | 由什么决定 | 写法要求 |
|---|---|---|
| 大类题型 | 连续相同的 `科目` | 同一大类的题必须挨在一起，**每行都填**；`行测·资料分析` 归一成 `资料分析` 作大标题 |
| 材料 | 大类内连续相同的 `材料` | 一则材料带 N 道小题时，这 N 行的「材料」列要**重复填同一段文本** |
| 题目 | 行序 | 题号按行序连续 `1..N`，材料组内不重新编号 |

三条硬规则：

1. **同材料的题必须连续**。中间插了别的题，就会被拆成两个材料组，材料在卷面上重复渲染。
2. **材料逐行重复**，不要只写组首行。留空表示「这道题不带材料」，会被当成独立题目。
3. **科目逐行填**。留空会并进「未分类」段，那一段不出大类说明卡。

以资料分析的一组小题为例（三行的材料单元格内容完全相同）：

| 题号 | 科目 | 材料 | 题干 |
|---|---|---|---|
| 3 | 行测·资料分析 | 2025年1—2月，某示范区…（全段） | 同比增加多少亿元？ |
| 4 | 行测·资料分析 | 2025年1—2月，某示范区…（同一段） | 上年同期约多少亿元？ |
| 5 | 行测·资料分析 | 2025年1—2月，某示范区…（同一段） | 占比约多少？ |

这样第 3–5 题会合成为一个材料组：单题浏览整组一页（材料固定上区、小题在下方悬浮面板，可拖手柄调占比），多题浏览时材料只挂在组首题上。

> 导入预览页会做一次「结构体检」：材料被拆到卷面不同位置、材料疑似只写了组首行、有题没填科目，
> 都会以整卷级提示列出来。只提示不改数据——自动沿用上一行材料会把紧跟其后的独立题误并进组。

## 题型写法

| 题型 | 可用写法 | 选项 |
|---|---|---|
| 单选 | `单选` / `单选题` / `选择` / `选择题` / `single` / `singleChoice` / `1` | 需要 |
| 多选 | `多选` / `多选题` / `多项选择` / `multi` / `multiple` / `multipleChoice` / `2` | 需要 |
| 不定项 | `不定项` / `不定项选择` / `不定项选择题` / `uncertain` / `partial` / `3` | 需要 |
| 判断 | `判断` / `判断题` / `judge` / `trueFalse` / `tf` / `bool` / `4` | 需要（A/B 或 T/F） |
| 填空 | `填空` / `填空题` / `fill` / `blank` / `cloze` / `5` | 不需要 |
| 主观 | `主观` / `主观题` / `简答` / `申论` / `材料分析` / `论述` / `essay` / `subjective` / `6` | 不需要 |

题型留空时按单选题处理；写了个认不出的词会警告「无法识别的题型，按单选题处理」，不会中断导入。

## 答案写法

| 题型 | 写法 | 示例 |
|---|---|---|
| 单选 | 一个选项字母 | `A` |
| 多选 / 不定项 | 多个字母，逗号分隔 | `A,C,D` —— Excel 单元格里直接写，不用加引号 |
| 判断 | 中文或符号都行 | `正确` / `错误` / `对` / `错` / `√` / `×` / `T` / `F` / `A` / `B` |
| 填空 | 多个空用 `\|` 分隔 | `人民代表大会制度\|全国人民代表大会` |
| 主观 | 整段参考答案，另配「得分点」列 | 得分点写 `关键词1;关键词2` |

答案也可以写成 `答案:A`、`A. 选项原文`（会按选项字母归一化），前后空白无所谓。

**答案可以不写。** 整列缺失、或某几行为空时，这些题以「待补答案」入库：能正常答、正常交卷，只是暂不判分。
补答案的流程见 [04 答案后补](04-答案后补.md)。

## Excel 怎么写

一张表一行一题，表头按「字段总表」的别名识别；表头示例见 [templates/试卷模板.xlsx](../templates/试卷模板.xlsx)
（里面还有一张「使用说明」表，导入时会被自动跳过）。

```text
题型 | 题干 | 材料 | 图片 | 选项A | 选项B | 选项C | 选项D | 答案 | 解析 | 知识点 | 难度 | 地区 | 科目 | 来源 | 年份 | 分值
```

要点：

* **只有「题干」必填**；选项列用不到的留空；
* 多行内容（长题干、材料）直接在单元格里 `Alt + Enter` 换行；
* 多选答案在单元格里直接写 `A,B,D`；
* 只想给一列选项时，表头写「选项」，单元格里按 `A. xxx` 换行写；
* 同一份文件里**内容完全重复**的题只保留第一道（预览页显示「重复跳过 N」），去重按卷内做；
* **每个工作表各成一份试卷**（sheet 名即卷名），多出来的「使用说明」表没有题就自动忽略，详见下一节；
* 支持共享字符串、内联字符串、数字、布尔、公式缓存值；
* **不读**单元格里的图片、批注、颜色；
* 合并单元格不会展开，只有左上角那个单元格有值——题干、材料这类长文本别跨行合并。

#### 没有表头也能进

表头一个都认不出来时，不再直接失败，而是**按内容形状推断列**：

* 整列非空值都是单个字母 `A`–`H` → 答案列；
* 非空、平均字数最长的一列 → 题干列；
* 题干右侧连续、长度适中、取值互不相同的列 → 选项 A/B/C…；
* 能推断出来就照常导入，并在校验问题里给出 WARN：`没有表头，已按内容推断列含义：第 2 列 → 题干，第 5 列 → 答案`；
* **推断不出「题干 + 答案」或「题干 + 选项」这种能自证的结构时仍然报错**，绝不猜着导错。

推断只是兜底，能写表头就写表头——列含义一旦猜错，错的是整份卷子。

## 一份 Excel 放多份试卷

**一个工作表 = 一份试卷**，sheet 名就是卷名。行测真题按套分表放在同一个 xlsx 里（`2023国考` / `2024国考` / …），
一次导入就能建出多份卷子，不用先拆成多个文件。

导入页还可以**一次选多个文件**：每个文件在试卷列表里成一个**标题**（导入组，默认取文件名，导入前可改），
文件里拆出的各份卷挂在这个标题下面。整个 App 只有「标题 → 试卷 → 题目」这三层，没有单独的「题库」层。

```
行测真题合集.xlsx
├─ 2023国考   → 试卷「2023国考」
├─ 2024国考   → 试卷「2024国考」
└─ 使用说明   → 没有题目，自动忽略
```

规则：

* 每张表**各自认表头**，一张表一套列顺序也没问题；
* 卷名取 sheet 名；`Sheet1` / `工作表1` 这种默认名没意义，回落到「文件名-序号」；
* 单张表的文件行为完全不变：整份文件一份卷，卷名取文件名；
* 去重、结构体检、答案开关都**按卷各算一遍**——同一道真题出现在两套卷里是正常的，不会被当成重复吞掉；
* 某张表解析不出题（说明页、答题卡页）只提示，不报错；一张表都没出题才逐张报原因。

导入预览页顶部会出现一排卷名胶囊，点一下切换预览，每份的勾选各自保存，最后一次性建卷。
两张表同名时（很少见）会在卷名后补上表名，不会互相覆盖。

### 表内再细分：「试卷」列

一套卷懒得拆表、几十套排在同一张表里时，加一列「试卷」即可按行分组：

| 试卷 | 题干 | 选项A | 选项B | 答案 |
|---|---|---|---|---|
| 2023国考 | 第一题… | 甲 | 乙 | A |
|  | 第二题… | 甲 | 乙 | B |
| 2024国考 | 第三题… | 甲 | 乙 | C |

* 表头别名：`试卷` / `试卷名` / `卷名` / `套卷` / `paper` / `examName` …
* 单元格留空表示**沿用上一份卷名**（合并单元格只在首行留值是常态），不用逐行填；
* 一张表里只写一个卷名时不算拆分，仍按整表一卷处理；
* 它只在一张表**内部**起作用：两张表不会因为卷名相同而被合并。

## 材料：表格、图片、图表

「材料」是一个纯文本单元格，支持 Markdown 表格、图片和 `:::chart` 数据图表。

### 「图片」列：题图专用

不想把图片写进材料文本，也可以单独留一列「图片」（别名 `配图` / `插图` / `image` / `img`…）：

* 一个或多个图片地址，多张用换行 / 竖线 `|` 分隔；
* 导入时自动转成 Markdown 图片**前置到材料顶部**——题图出现在题干上方，材料文本跟在图后面；
* 已写成 `![..](..)` 的原样保留；来源与材料内嵌图片一致（本地路径 / `content://` / base64 / 试卷包内相对路径）。

### Markdown 表格

```markdown
1—2月，中关村国高新企业实现总收入5280.0亿元，同比增长5.8%。

| 指标 | 2024年1—2月 | 2025年1—2月 |
| --- | --- | --- |
| 总收入（亿元） | 4990.5 | 5280.0 |
| 研发费用（亿元） | 597.0 | 611.9 |
```

渲染成真表格：列宽按内容自适应整屏宽度（列多时自动缩字号），不会截掉右列，夜间模式跟着换色。

### 图片

单独一行写图片地址即可，按材料宽度铺满、最高 420dp，点一下整屏看大图：

```markdown
![2024—2025年2月总收入与研发费用同比增速](/sdcard/Download/试卷/chart-01.png)
```

| 图片来源 | 写法 | 说明 |
|---|---|---|
| 本地文件 | `/sdcard/Download/试卷/图1.png` 或 `file:///...` | 最稳，建议图和试卷放同一目录 |
| 相册 / 文件选择器 | `content://media/...` | 只在本次运行内有效，重启后授权可能失效 |
| 应用内置图 | `asset://samples/xxx.png` | 仅用于内置示例 |
| 自包含 | `data:image/png;base64,...` | 图直接写进单元格，试卷不依赖外部文件（体积变大） |
| 试卷包内 | `images/chart-01.png` | **推荐**，见 [03 试卷包](03-试卷包.md) |

也认 `[图片](路径)` 和「整行只有一个图片路径」两种写法。图片只做本地解码，不申请网络权限，**不支持 http 图片**。

### :::chart 图表

没有配图时，可以让 App 按数据自绘折线 / 柱状图（纯文本试卷、Excel 不方便带附件时用）：

```markdown
:::chart
title: 2024—2025年2月中关村企业总收入、研究开发费用合计同比增速（单位：%）
type: line
x: 2024年1—2月, 1—3月, 1—4月
series: 总收入同比增速=8.9, 7.2, 7.0
series: 研究开发费用合计同比增速=3.7, 4.3, 2.8
:::
```

| 键 | 说明 |
|---|---|
| `title` | 图表标题（也认 `标题`） |
| `type` | `line` 折线（默认）/ `bar` 柱状（也认 `柱状`） |
| `x` | X 轴标签，逗号 / 顿号分隔 |
| `series` | `名称=值1,值2,…`，可写多行；缺值写 `-`，折线在该点断开 |
| `min` / `max` | 手动指定 Y 轴范围，不写就按数据自动取整刻度 |
| `showValues` | 是否在数据点标数值，默认 `true` |

也认 ` ```chart ` 围栏。格式写错不会静默吞掉，材料里会显示「图表数据格式有误」。
自绘的好处是日夜两套配色、字号随卡片缩放，试卷始终是纯文本。

## 选项里的图片

图形推理这类题，选项本身就是图——直接把图片地址写进选项单元格就行，写法与材料图片完全一致：

| 选项A | 选项B | 选项C | 选项D |
|---|---|---|---|
| `![图1](images/A.png)` | `![图2](images/B.png)` | `/sdcard/试卷/C.png` | `[图片](images/D.png)` |

* 认 `![说明](路径)`、`[图片](路径)`，以及**整格只有一个图片地址**（导出工具常见）；
* 图片按选项正文宽度铺开、最高 240dp；**点图就是选这一项**，不会弹大图预览；
* 「文字 + 图」也支持：文字在上、图片在下，多张图按出现顺序竖排；
* 试卷包内的相对路径会在导入时换成本机绝对路径（与材料图同一套逻辑）；
* 试卷列表 / 导入预览里选项只显示成「［图片］」，不会把一长串路径糊到界面上。

## 校验提示对照

导入预览里的每条提示都带行号。按级别处理：

### 错误（该题或整份文件被丢掉）

| 提示 | 原因 | 怎么改 |
|---|---|---|
| `只支持 Excel（.xlsx）文件…` | 选的不是 Excel（老格式 json / csv / txt 已不再支持） | 另存为 `.xlsx`，或用 [templates/试卷模板.xlsx](../templates/试卷模板.xlsx) 重填 |
| `未找到「题干/题目/stem」列，无法识别表头` | Excel 表头里没有题干列 | 表头改成 `题干` 或 `题目` |
| `题干为空，已跳过` | 该行题干列是空的 | 补题干，或删掉这行 |
| `未识别到选项列，无法作答，已跳过` | 既没有选项也没有答案 | 补 A–D 列；或确认题型不是填空/主观 |
| `当前版本仅支持选择题，该题已跳过` | 填空 / 主观题且没有选项 | 见 [只支持选择题的原因](#只支持选择题的原因) |
| `文件内容为空` / `Excel 中没有可读数据` | 选错文件、文件是空的，或内容全在图片里 | 把内容落到单元格 |

### 警告（导入成功，但可能不是你想要的）

| 提示 | 含义 |
|---|---|
| `无法识别的题型「X」，按单选题处理` | 题型写了个陌生词，检查拼写 |
| `缺少答案，已按「待补答案」导入` | 正常现象，之后补答案即可 |
| `未识别到选项列，已按多选题处理` | 有多个答案字母但没有选项列，看看表头是否漏了选项 |
| `未识别到选项列，已按填空题处理` | 同上，单答案 + 无选项 |
| `当前版本仅支持选择题，已按单选题处理` | 填空/主观题带选项，被降级 |
| `答案 X 不在选项范围内` | 答案字母没有对应的选项，多半是选项列错位 |
| `单选题给出多个答案，已按多选判题` | 题型与答案自相矛盾，以答案为准 |

### 提示（说明性）

`判断题选项沿用 A/B，实际按「正确/错误」判题` —— 判断题用 A/B 选项是支持的，判题时会归一化。

## 判题口径

| 题型 | 规则 |
|---|---|
| 单选 | 答案键完全一致才得分 |
| 多选 | 默认**全对才得分**（多选/少选/错选均不得分），设置里可开「少选给部分分」 |
| 不定项 | 全对满分；少选给 50%（可配）；错选 0 分 |
| 判断 | 归一化 `T/F/对/错/√/×/Y/N` 后比对 |
| 填空 | 多空用 `\|` 分隔，逐空比对（忽略空白/标点/全角），漏空可给部分分 |
| 主观 | 按「得分点」关键词命中率给分，全部命中为满分 |
| 无标准答案 | 标为「待补答案」，不判分；不计满分、不计正确率分母、不计答错 |

---

## 只支持选择题的原因

答题流程当前只完整支持选择题（单选 / 多选 / 不定项 / 判断）：

* 答题页不渲染填空输入框与主观题作答区；
* 文件里若存在填空 / 主观题，**带选项的降级为单选题**，不带选项的直接跳过（报错并给行号）；
* 数据模型层仍保留 `FILL` / `SUBJECTIVE` 与对应判题规则（`engine/Judge.kt`），后续放开只需改答题页。
