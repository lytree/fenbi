# 03 题库包（zip）

材料里写绝对路径，换台设备就丢图。**题库包**把主数据和素材打成一个 zip，导入时自动解压到应用私有目录，
材料里的相对路径会在入库前换成解压后的绝对路径——之后翻题不必再算包内位置。

---

## 标准目录结构

```
资料分析题库包.zip
└── 资料分析题库包/            ← 外层目录可有可无
    ├── qbank.json            ← 必需：题库主数据
    ├── images/               ← 可选：材料配图
    │   ├── chart-01.png
    │   └── chart-02.png
    └── README.txt            ← 可选：说明文件，不参与导入
```

主数据就是普通的 JSON / CSV / Excel 题库（写法见 [02 题库格式规范](02-题库格式规范.md)），
材料里的图写**包内相对路径**：

```json
{
  "bank": "资料分析题库包",
  "description": "材料配图随包分发",
  "questions": [
    {
      "type": "单选",
      "stem": "2025年1—2月，总收入约比上年同期增加多少亿元？",
      "options": { "A": "289", "B": "306", "C": "258", "D": "320" },
      "answer": "A",
      "material": "1—2月，……同比增长5.8%。\n\n![增速](images/chart-01.png)"
    }
  ]
}
```

## 规则

| 项 | 规则 |
|---|---|
| 主数据文件名 | 优先 `qbank.json` → `questions.json` → `bank.json` → `题库.json`；都没有时，取包内**唯一**的 json / csv / xlsx |
| 外层目录 | 压缩软件默认「再包一层文件夹」不影响，单层自动剥掉 |
| 图片引用 | `images/x.png` 或 `./images/x.png`，导入时替换成解压后的绝对路径再入库 |
| 内嵌格式 | 主数据可以是 JSON / CSV / Excel；图片统一放 `images/` |
| 默认试卷名 | 主数据里的 `bank` / `name` / `title` / `名称` / `题库`，没有则沿用 zip 文件名（导入页可改） |
| 解压位置 | `filesDir/qbank_pkg/<包名>-<CRC32>/`；同一个包重导入复用同一目录，内容变了换新目录，不会新旧图混用 |
| 路径安全 | `..`、绝对路径、`__MACOSX/` 这类条目直接跳过，绝不会写到包外 |
| 体积上限 | 单个文件 32 MB，解压总量 256 MB |
| 嵌套 | 包内不能再放 zip；答案文件也不支持 zip |

几个容易出错的地方：

* **文件名编码**：建议 zip 内的文件名用 UTF-8（macOS / Linux 默认就是），个别老压缩工具会写 GBK，中文名会乱码。乱码不影响图片按 ASCII 命名的包，但中文文件名建议避开。
* **主数据别放深层目录**：兜底推断只往下看一层（`depth <= 1`），命名成 `qbank.json` 最稳妥。
* **URL 里别带空格**：`images/my chart.png` 在 Markdown 里要写成 `images/my%20chart.png`，或者干脆用 `chart-01.png` 这类名字。
* **图片只做本地解码**，不申请网络权限，包内图不要写 http 地址。

## 打包

整个文件夹压成 zip 即可，不需要特定工具：

```bash
# macOS / Linux
cd sample && zip -r 资料分析题库包.zip 资料分析题库包

# Windows（PowerShell）
Compress-Archive -Path .\资料分析题库包\* -DestinationPath .\资料分析题库包.zip
```

仓库自带两个示例，可以直接导入体验：

* `sample/资料分析题库包/`（目录形态）
* `sample/资料分析题库包.zip`（打包结果，由 `python sample/make_package.py` 生成）

导入页「载入示例题库 → 资料分析题库包（zip）」即用后者。
想从零开始，用 [templates/题库包模板.zip](../templates/题库包模板.zip)：2 道题、1 张示例图，结构照抄即可。

## 什么时候不用题库包

| 情况 | 建议 |
|---|---|
| 材料里没有图，或图是 `:::chart` 自绘的 | 普通 json / csv / xlsx 就够，纯文本好维护 |
| 图很少、只在自己手机上用 | 直接把图放 `/sdcard/Download/` 下写绝对路径 |
| 要发给别人 / 换设备 | 用题库包，否则对方的图一定丢 |
