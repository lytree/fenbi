# 04 答案后补

「题目先到、答案后到」是最常见的真实情况：先导一份没有答案的卷子做完，再拿一份答案文件补上，
**按已有作答直接重判**，不用重做一遍。解析同理——**解析可以单独后补、单独导入**，见文末
[「解析也可以单独补」](#解析也可以单独补)。

---

## 第一步：导入没答案的试卷

答案列整列缺失、或某几行为空，都不再报错跳过，只给一条警告：

```
第 12 行 · 缺少答案，已按「待补答案」导入
```

* 导入预览的统计里多一项 `缺答案：N`；
* 题目列表上会标出「待补答案」；
* 这些题能正常答、正常交卷，只是暂不判分——**不计满分、不计正确率分母、也不算答错**。

不想显示警告行也可以：把答案列整列删掉，行为一样。

### 文件里本来带答案，也可以选择不导入

导入预览页的「生成试卷」卡里有一个 **同时导入答案** 开关，默认开着：

* 开着：照旧把文件里的答案一起入库；
* 关掉：**只导入题目**，答案（主观题连关键词一起）一律清空，预览行显示「答案：待补答案」，
  统计行改显示 `本次不导入答案（N 题）`。

适合「文件里那份答案不想要 / 想自己边做边对」的场景——之后照样能补答案，补完按作答重判。

---

## 第二步：做完之后补答案

补答案有两个方式，入口都在 **成绩报告** 里（右上角「补答案」）：

| 方式 | 说明 |
|---|---|
| **逐题补录** | 不用准备任何文件，进补录页把答案一道道填进去，保存即按你的作答重判 |
| **导入文件** | 选一个 Excel，App 自动识别是答案（`题号,答案`）还是解析（`题号,解析`），按题干 / 题号自动匹配——不用先想清楚文件里装的是什么 |

其他入口：

| 入口 | 位置 |
|---|---|
| 答题页 | `更多 → 导入答案（N 题待补）`（答案文件）、`更多 → 补录答案（手动逐题填）` |
| 交卷时 | 点「交卷」，若本卷还有待补答案，弹窗提供「导入答案 / 直接交卷」 |
| 成绩报告 | 右上角「补答案」→ 逐题补录 / 导入文件；待补答案的提示条点一下也直接进补录页 |
| 试卷列表 | 长按试卷 →「导入答案」 |

### 逐题补录（不用文件）

补录页一行一道题：题号、题型、你自己选的答案、题干，下面一个输入框填标准答案。

* 选择题填字母：单选 `A`，多选 `A,C` 或 `ABC` 都认；
* 判断题填 `对` / `错`（`正确` / `错误` / `T` / `F` 也认）；
* 留空的题保持「待补答案」，不计入判分；把已有答案删空则退回待补状态；
* 右上角 **批量粘贴**：把 `1.A 2.B 3.对`、一行一题、或者干脆只贴一串 `A B C D`（按题序填）粘进来，
  自动按题号落位，没题号的补到还没填的题上；
* 底部 **保存并批改**：写入后立刻按这条记录里的原作答重判，返回报告页就是新成绩。

---

## 答案文件怎么写

统一只支持 **Excel（.xlsx）**（不支持 zip）。最标准的是「题号 / 答案 / 解析」三列表：

| 题号 | 答案 | 解析 |
|---|---|---|
| 1 | B | 乙项符合题意 |
| 2 | A,B,D | |
| 3 | 正确 | 行政复议不收费 |

* 表头能识别就按表头走（`题号` / `答案` / `解析` / `题干`）；
* 认不出表头时按位置约定：**第一列题号、第二列答案、第三列解析**；
* 多选答案单元格里直接写 `A,B,D`；
* 也可以直接拿原试卷的答案版（带「题干」列的完整 Excel）当答案文件用，此时按题干匹配，题序被打乱也不影响。

逐题手填的「批量粘贴」不受影响：`1.A 2.B 3.对`、一行一题、或只贴一串 `A B C D` 都认——那是手输文本，不走文件导入。

---

## 匹配规则

1. **题干优先**：归一化（去空白/标点/全半角差异）后全等，且题干长度 ≥ 8 个字——答案文件题序被打乱也能对上；
2. **其次按题号**：1 起，对应卷内顺序；
3. **最后按顺序**：既没题号、题干也对不上（纯答案列表）时，按顺序填给尚未匹配的题。

写入前会弹窗告知，确认后才落库：

* 匹配上了几题（N/M）；
* 哪几题的**原有答案会被覆盖**；
* 哪几题没匹配上；
* 答案条数多于待补题目时，多出的部分会被忽略。

补完答案后：

* 「待补答案」清零，这些题重新参与计分；
* 成绩报告按记录里保存的**原作答**重新判分，得分 / 正确率 / 逐题解析一起刷新；
* 答题记录本身不会新增一条。

---

## 注意

* 答案会按**题目自己的题型**归一化：判断题 `正确` → `T`，多选字母排序去重，填空按 `|` 拆分；
* 一道题的答案只写一次；题号重复时保留先匹配到的那条，并在提示里说明；
* 补答案不改题目的其他字段（解析会用答案文件里的解析覆盖，若答案文件带了的话）；
* 已全部有答案的卷子也可以补，用来纠错——只是覆盖提示会更显眼。

答案侧的最小模板见 [templates/答案模板.xlsx](../templates/答案模板.xlsx)。

## 解析也可以单独补

解析和答案是两条独立的写入通道：答案文件只动答案（带了解析列才顺带写），
**解析文件只动解析，答案一个字都不改**。适合「答案早就有了、解析后来才整理好」的节奏。

### 入口

只有一个入口，不用单独区分：

| 入口 | 位置 |
|---|---|
| 成绩报告 | 右上角「补答案」→ **导入文件（自动识别答案 / 解析）** |
| 答题页 / 试卷列表 / 交卷时 | 「导入答案」入口同一条流程——**答案列整列缺失的文件会自动按解析导入**，确认弹窗里会写明「本次只导入解析，答案保持不变」 |

### 解析文件怎么写

统一只支持 **Excel（.xlsx）**（不支持 zip），最标准的是「题号 + 解析」两列表
（最小模板见 [templates/解析模板.xlsx](../templates/解析模板.xlsx)）：

| 题号 | 解析 |
|---|---|
| 1 | 同比增长量 = 611.9 − 611.9 ÷ (1 + 2.5%) ≈ 14.9（亿元） |
| 2 | 表中已直接给出 4990.5 亿元 |

### 规则

* 判定标准：文件里**所有条目都没有答案、只有解析** → 按解析文件导入；答案 + 解析两列都有的文件仍按答案文件走；
* 匹配与答案文件完全一致：**题干优先 > 题号 > 顺序**；
* 只覆盖解析，已有解析会弹窗提示；只要文件里有答案列就会整体按答案文件走（解析列顺带写入）；
* 解析补完立即生效：交卷后的逐题解析、答题页练习模式的内联解析都会显示新内容，不用重做。
