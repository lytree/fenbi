# 05 界面与交互

界面遵循刷题类应用的通行范式，全部为独立实现，不含任何第三方应用的代码与资源。

样式只有**三个来源**，改皮肤只改这三处：

| 文件 | 装什么 | 规矩 |
|---|---|---|
| `res/values/colors.xml` | 色板（品牌 / 中性 / 文字六级 / 状态 / 图表 / 夜间） | 布局与 drawable 里**不写 `#RRGGBB`** |
| `res/values/dimens.xml` | 间距、圆角、字号、组件尺寸 | 布局里**不写字面量 dp / sp** |
| `res/values/styles.xml` | 组件样式（卡 / 按钮 / 标签 / 底栏 / 空态 / 弹窗…） | 布局里优先 `style=`，只覆写差异项 |

> 平板（`values-sw600dp` / `values-sw720dp`）只覆盖需要放大的令牌，不复制整套。
> 放大能力时**圆角跟着间距走**（按钮 50dp 高 → 胶囊半径 25dp），否则会出现「大按钮小圆角」。

### 间距与圆角

* 间距只用 4 的倍数：`fb_space_4 / 8 / 12 / 16 / 20 / 24 / 32`

### 页面骨架

所有页面都是同一副骨架，新页面照抄即可：

```
LinearLayout  style=FbPage
├─ FbTitleBar                 ← 44dp 白底 + 状态栏 inset + 0.5dp 底分割线
├─ 内容（RecyclerView / NestedScrollView；内层 FbPageColumn）
└─ FbDivider + FbBottomBar    ← 只有需要主操作时才有
```

* 列表页 = `item_*.xml` 用 `FbListCard`（白卡 + 左右 16 + 卡距 12），页面不额外加 padding；
* 空态 = `FbEmptyBox` + `FbEmptyText`（+ 可选 `FbEmptyAction`），不再各页面手写一份；
* 答题卷面是**例外**：白底通铺、不用卡片，题与题之间只隔 0.5dp 细线，左右留白走 `fb_content_padding_h`（约 5% 屏宽）。

### 弹窗

**全站不使用系统 `AlertDialog`**（Material 那套左对齐标题 + 文字按钮 + 大圆角，一眼看出不是这个 App）。
统一走 `FbDialog` 的四种形态（`res/layout/dialog_fb_*.xml`）：

| 方法 | 用在 | 样子 |
|---|---|---|
| `FbDialog.confirm` | 交卷 / 删除 / 退出确认 | 居中白卡 12dp 圆角 + 两个等宽胶囊按钮 |
| `FbDialog.alert` | 出错 / 单按钮告知 | 同上，只留一个按钮 |
| `FbDialog.list` | 长按菜单 / 多选一 | 底部弹层：52dp 动作行 + 独立「取消」块 |
| `FbDialog.input` | 笔记 / 批量粘贴 | 居中白卡 + 多行输入框 |

### 图标

24dp 线性图标统一 **1.7 线宽**（strokeLineCap/Join 均为 round），颜色只引 `fb_icon`（常规）、
`fb_text_placeholder`（chevron）、`fb_nav_normal`（底部导航，实际由 tint 控制）。
两个刻意的例外：题号行的「标记星」细一档（1.4，用来和右侧收藏星区分）、18dp 搜索图标按视口比例取 2.1。

## 答题页

* 顶栏 44dp：`X` 关闭 / 闹钟 + 倒计时胶囊 / 居中标题「试卷名（题数）」（13sp 常规字重，长卷名整行塞得下）/ 右侧导出·交卷·答题卡·更多
* 卷面：**整页白底通铺**，题目不再是独立圆角卡片，题与题之间只有一条 0.5dp 细线（对齐参考应用真机）
* 题目行：题号 + 浅蓝题型标签，右侧三图标按参考应用口径 —— **细线星（标记）/ 笔（写画）/ 星（收藏）**
* 选项：圆形 A/B/C/D 徽标（32dp，选中变蓝色实心圆）+ 单列正文，行距松、不画分隔线；**徽标与正文上下居中**——选项换行成多行时圈落在文字块中间，不贴第一行顶
* **模块说明卡**：按题目的 `subject` 聚合，同一模块只在**首题上方**出现一次 —— 浅蓝渐变圆角块 + 「资料分析 (5题)」标题 + 该模块的官方作答说明（资料分析 / 数量关系 / 言语理解 / 判断推理 / 常识判断各一套文案）。`subject` 为空的试卷不渲染这张卡，不会给手打试题硬塞一个空标题
* **没有底部操作条**：上一题 / 下一题交给滚动与左右滑动，跳题用答题卡

### 单题 / 多题切换

`更多 → 多题浏览 / 单题浏览`：

| 模式 | 容器 | 行为 |
|---|---|---|
| 多题浏览 | `QuestionListAdapter` + 连续滚动列表 | 一屏多题，上下滚动 |
| 单题浏览 | `QuestionPagerAdapter` + `ViewPager2` | 一屏一题，左右滑动切题；长题干可在页内纵向滚动 |

**一则材料带多道小题时整组占一页**（单题浏览）：`QuestionPagerAdapter` 的页码表按「同一则材料」聚合，
资料分析那种一篇材料 + 5 道小题的题组不再一题一页——整组放同一页，采用**上下分栏**版式
（`item_group_pager_page.xml`）：材料固定上区独立滚动，小题放底部**悬浮面板**（顶部圆角 + 投影）
里独立滚动、依次往下排，中间手柄上下拖动调节占比（20%～80%，存 `exam_prefs/group_split_ratio`），
翻页只发生在题组之间。
「自动展示下一题」在组内不翻页，而是把下一道小题滚到面板顶部；答题卡跳题 / 点某题的「笔」也同样会滚到页内那一题。
笔迹按**卡**锚定，组页上圈画不会因为页内换题而消失。

两套容器共享同一份题目卡渲染（`QuestionCardBinder`），切换时按「当前正在看的题」双向定位，
答案、标记、收藏、字号、交卷后的解析全部同步；选择会持久化，下次进入沿用。

### 计时与交卷

倒计时、剩 5 分钟提醒、超时自动交卷；交卷二次确认（「你还有 N 道题目未作答，确定交卷吗？」）。

### 答题卡

顶栏「答题卡」打开底部弹层：按模块分组的圆形题号网格，已答蓝实心、未答浅灰蓝、当前题带淡蓝环，
标记 / 收藏挂小圆点，底部通栏「交卷」。

弹层是**透明窗口**（`Theme.QBank.Popup` + `windowIsTranslucent`），不是另起一屏——
弹出来时答题页仍在下面可见（压一层 40% 遮罩），点题号跳题或交卷后弹层滑下去，答题页接着用。
遮罩色 `fb_sheet_mask` 只用 40% 黑，再深就把下面的卷面盖掉了；系统栏底色也取遮罩色，
避免透明窗口上方多出一条主题白带。进出场由 `AnswerCardActivity` 自己驱动（上滑 200ms / 下滑 160ms），
并 `overridePendingTransition(0, 0)` 关掉 Activity 默认转场，否则默认转场会把答题页一起推走。

## 平板适配

断点用系统标准的 **最小宽度 ≥ 600dp**（与 `values-sw600dp` 资源目录同一口径），判定集中在
`ScreenAdapt` 里，界面自适应落在三处：

| 关注点 | 手机 | 平板 |
|---|---|---|
| 屏幕方向 | 锁竖屏（`ScreenAdapt.applyOrientation`，答题链路上每个 Activity 都要调，方向锁不继承） | 不锁，跟随设备旋转、铺满全屏 |
| 内容列宽 | 撑满屏宽 | 同样撑满屏宽（不设宽度上限，留白只由 `fb_content_padding_h` 预留） |
| 左右留白 | 22dp（≈5% 屏宽） | 32dp（sw600dp）/ 40dp（sw720dp），均按「约 5% 屏宽」取值 |
| 字号 / 触控目标 | 16sp 正文、32dp 选项圆标 | 19sp 正文、46dp 圆标、52dp 答题卡格子 |

**不要在 `AndroidManifest.xml` 里给答题页写 `android:screenOrientation="portrait"`**：
平板（Android 12L+ 以及各家 ROM 的兼容模式）会据此判定「应用不支持大屏」，把整个页面塞进
一块手机比例的窗口、两侧留黑边——表现就是「答题页被收缩成手机」。方向改在运行时按形态决定。

列宽**不由适配器按 `displayMetrics.widthPixels` 反算左右 margin**（多窗口、分屏、旋转时那套算法都不准），
也**不设最大宽度**：`activity_exam.xml` 里多题列表（`questionList`）与单题浏览（`pager`）都是
`layout_width="0dp"` + 左右约束到父容器，直接铺满可用宽度；宽屏（平板 / 横屏）不做居中窄列，
左右留白只由题块内部的 `fb_content_padding_h` 预留。两种浏览模式规则完全一致。

答题卡列数按 `fb_card_num_size` 与屏宽实算（`5..14` 列），平板上格子放大而不是把 40dp 的格子
在一行里摊得更散。

## 夜间模式

`更多 → 夜间`。这是「答题流程内」的局部换色，**不走系统 `DayNight`**（原因见下），所以每一层都显式换色：

| 范围 | 覆盖内容 |
|---|---|
| 答题页 | 页面底 / 顶栏 / 顶栏 5 个图标 / 题号 / 题型标签 / 标记·笔记·收藏 / 题干 / 选项文字与圆形徽标 / 材料区与表格 / 笔记·解析 |
| 更多面板 | 面板底 / 分段控件轨道与选中胶囊 / 字号档位文字 / 自动下一题与手写标注的开关轨道 |
| 遮盖层工具条 | 悬浮胶囊底与按钮文字；遮盖纸由白纸换深色纸（`InkOverlay.night`） |
| 答题卡弹层 | 弹层底 / 标题行 / 分组标题 / 未答题号 |
| 系统栏 | 状态栏与导航栏的底色、图标明暗 |

夜间色板集中在 `colors.xml` 的 `fb_night_*`，圆角、字号、间距一律复用日间令牌，切换时版式零位移。
偏好持久化，重进直接生效。

> 已知边界：资料分析左右分屏页（`SplitExamActivity`）目前仍是日间配色，尚未接入夜间。

## 题目遮盖层（写画模式）

做纸质卷子的手感：想写就写，但不想在写字时把选项点掉、把题翻过去。
所以**不是**加一层透明浮层，而是给题目盖一张可写的薄纸——`InkOverlay` 既是画布，也是触摸拦截层。

入口是题目卡右上角那支笔：**点 = 给这一题盖纸上写**（题目会自动顶到内容区最上面，写起来顺手）；
**长按 = 文字笔记**。

笔迹**钉在题目或材料上**，不是钉在屏幕上：`InkOverlay` 用「内容左上角」当原点把每一笔存成相对坐标，
卷面滚到哪、切到哪种浏览模式，圈画都还落在原来那句话上。题目与材料各有独立锚点：
材料块上的圈画跟着材料正文走，不会因为题干换行而整体偏移，也不会串到题目上。

标注**跟随本次作答记录**保存：进卷先落一条草稿记录，交卷时转正；换一轮练习就是另一套圈画。
同一记录里每个题 / 每份材料只保留**最新一份批注**，撤销和清空即时落库，退出重进照样在，回头想补一笔直接再点那支笔就行。

![从题目卡上的笔进入写画](images/fenbi-ink-pen.png)

写画模式下屏幕右侧有一条细轨道（横屏可见），按住上下拖就能滚题目，笔迹跟着文字走：

![边缘轨道滚动](images/fenbi-ink-edge-scroll.png)

| 项 | 行为 | 实现 |
|---|---|---|
| 入口 | 题目卡右上角「笔」（点=写画，长按=笔记）；`更多 → 手写标注·遮盖`；分屏页底部「手写标注」 | `QuestionCardBinder` + `InkToolbarController`，开关与工具条共享同一份状态 |
| 遮盖 | 四档：关 / 浅 / 中 / 深（alpha 0 / 24 / 58 / 110）；日间铺白、夜间铺黑 | `InkOverlay.Shade`，档位存 `ink_prefs`，跨题跨页面记住 |
| 输入 | 手指、触控笔都能写；按笔迹跟踪单个触点，掌托 / 第二指不打断 | `activePointerId` + `findPointerIndex` |
| 拦截 | 写画模式下吞掉全部触摸，不透传选项、不许翻页 | `onTouchEvent` 全 `return true` |
| 滚动 | 贴屏幕最右边一条上下拖，滚当前题目容器，那里不落笔；分屏页左边缘也有同样一条滚材料 | `scrollTargetResolver` + `barTouchWidth` |
| 竖屏 | 不画手柄（屏幕窄），热区收窄到 16dp 贴边 | `railVisible = false` |
| 退出 | 点「完成」只退出写画：**笔迹留着**、触摸恢复 | `writeMode = false` → `isEnabled = false` |
| 持久化 | 笔迹按「作答记录 + 目标（题目 / 材料）」存 `record_inks` 表（v2 格式：每笔带颜色 + 相对内容坐标）；同一记录同一目标只留最新一份，撤销到空即删行 | `InkOverlay.recordId` + `QBankDb.ensureDraftRecord()/finalizeRecord()` |
| 撤销 | 撤销最后一笔 / 清空当前目标；写材料时撤销材料，写题目时撤销题目，立即落库 | 工具条「撤销 / 清空」→ `InkOverlay.undo()/clear()` |
| 内容锚定 | 题目锚点 = 卡片左边 + 题干顶边；材料锚点单独取材料正文，命中区裁到滚动容器可视范围 | `inkAnchors()` → `InkOverlay.Anchor` + `hitRegion()` |
| 笔迹颜色 | 五色：红 / 蓝 / 绿 / 橙 / 黑；每笔各存各的颜色，换色不影响已写的 | `PenColors`（`ink_prefs / pen_color`），设置页与工具条色点共用 |
| 标记 | 工具条「标记」与题目卡书签、答题卡是同一份 `marked` 数据；答题中按试卷存 `exam_progress`，交卷时随本次作答写入 `records.marked`，报告逐题标「已标记」 | `InkToolbarController.setMarked` + `QBankDb.finalizeRecord()` |

![遮盖与笔迹](images/fenbi-ink-mask.png)

### 四个容易踩的点

1. **不能只是 `GONE`** —— 早期实现「完成」就把整层隐藏，笔迹跟着消失；现在常驻可见，只切拦截开关；
2. **不能只认 `TOOL_TYPE_STYLUS`** —— 没笔的人永远写不出来；两种输入都收，靠「写画模式」这个显式开关区分；
3. **不能按 `pointerCount` 判多指** —— 用笔时掌托一落就断笔；改成锁定落笔那一根指针；
4. **卡片上的笔必须真的接进写画** —— 早先这支笔绑的是「编辑笔记」弹窗，点了当然看不到画布。

### 滚动通道的两个坑

1. **`RecyclerView.computeVerticalScrollOffset()` 不能用来量位移** —— 那是给系统滚动条用的估算值（按平均项高折算），
   乘出来的笔迹会越滚越偏。改成直接读容器自己的真实偏移：`ScrollView` / `NestedScrollView` 看 `scrollY`，
   `RecyclerView` 看首个可见项 `top` 的变化；
2. **切换浏览模式后要让遮罩层重画一次** —— 容器刚从 `GONE` 转 `VISIBLE` 时还没排版，`canScrollVertically` 返回 false，
   轨道这一帧就不画；不补一次 `invalidate()` 会停在旧画面。

> 已知边界：旧版本按题全局存的 `inks` 没有记录归属，无法安全迁移到某一轮练习，升级后从新一轮开始记；
> 资料分析分屏页没有续做入口，退出未交卷会连同草稿和标注一起丢弃。单题浏览下当前页不满一屏时边缘拖不动，
> 先点「完成」再换题。

## 资料分析左右分屏

`更多 → 开启左右分屏`（仅本卷含材料题时出现）进入 `SplitExamActivity`：

* 顶栏按参考应用**只留返回 + 计时**（`FbTitleBar.setTimer()`，没有卷名与右侧动作），右上是组内进度
* 左侧材料：约 40% 宽，白底整栏、无外框，「材料」标签居左；Markdown 表格按栏宽自适应（列多时自动缩字号，不横向裁切）
* 右侧：该材料对应的全部题目**白底通铺、题间一条细线**，题号按整卷序号继续往下排（106. / 107. / 108.），这一组不再重复显示模块说明卡
* 中间一条 0.5dp 竖线 + 可拖动分隔手柄（25%～75%，占比记忆到偏好）
* 两栏都能用遮盖层做标注；左边缘有专门的滚动轨道
