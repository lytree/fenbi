# 11 背诵（词库 / 政治 / 常识）

底部导航第二项叫**背诵**（`tab_recite`），这一项下面分三块，靠页面顶部那条
「词库 / 政治 / 常识」切换互相跳转，切换只是 `replace` 一个 Fragment，底部导航仍高亮「背诵」。

| 段 | 页面 | 内容来源 | 说明 |
|---|---|---|---|
| 词库 | `WordListFragment` | `assets/builtin/words.csv` + 用户导入 | 成语 + 实词同表，搜索 / 分类 / 标签筛选，按拼音首字母分组 |
| 政治 | `ReciteOutlineFragment` | `assets/recite_library.json` | 统一库大纲：标签分支 + 条目行，见 [15 政治与导图重设计](15-政治与导图重设计.md) |
| 常识 | `ReciteFragment(COMMON)` | `assets/recite_common.json` | 填空卡流，左右滑切题、按住偷看 |

## 一、为什么是这三块

原来底部导航第二项叫「词库」，里面塞了三页（词库 / 成语 / 考点背诵）。成语和词库本来就是
同一批数据（成语只是 `category = idiom` 的那部分），分成两页反而要多点一次；而「考点背诵」
是政治理论的背诵卡，跟词库没有共同点。所以：

* 成语汇总页（`IdiomListFragment` + `IdiomRepository` + `assets/idioms.json`）**并进词库页**：
  它的搜索框挪到词库页顶部，归类浏览由标签筛选承担，词典数据本来就和内置词库重复。这几个文件已删除。
* 考点背诵改叫**政治**，和新增的**常识**并列，两者共用同一套背诵界面。

## 二、政治的形态：一棵标签大纲

政治在 2026-11 换过一次形态：原来「考点卡 + 思维导图」两个入口、两套分组，现在内容合并成一份库
（`assets/recite_library.json`，2216 条 = 卡片 1171 + 导图行 1045），页面只剩一个大纲。

```
▾ ▍新思想                                  12 / 532      ← 一级分支 = 内容标签，点击折叠
     超格 · 政治理论考情介绍+新思想导论                     ← 来源小字，视觉分段，不可折叠
     习近平新时代…是____相结合的重大成果        ○          ← 卡片：点行揭示答案，点圆点标记已背
     党的建设2 · 组织/作风/纪律/反腐
     ▍一体推进不敢腐、不能腐、不想腐…           ●          ← 导图行：depth=0 带主色短条
       重在「一体」，也难在「一体」                       ← depth 递增，每级缩进 14dp
```

* **板块 / 章节分组在资产里已经取消**，换成 18 个内容标签（+「未归类」281 条），标签就是一级分支；
* 导图不再是独立页面，它的原文行被拉平成大纲行；图形画布降级成 `⋯` 里的「鸟瞰导图」；
* 顶栏睁眼 = 答案常显，「只看未背」在进度行右侧，字号三档与常识共用同一份设置；
* 折叠状态、滚动位置、已背进度都落库，切到词库再回来还是原样。

设计口径、为什么这么改、还没做的（聚焦背诵、`cloze` 挖空、281 条人工归类）都在
[15 政治与导图重设计](15-政治与导图重设计.md) 里。

## 三、常识：仍是填空卡流

`ReciteFragment` 现在只服务常识：填空卡、左右滑切题、长按 / 轻点看答案、背诵模式、分组编排。
打开方式是 `ReciteFragment.newInstance(ReciteSubject.COMMON)`，页面从 `arguments` 里取
`recite_subject` 还原。

## 四、常识内容怎么填

`assets/recite_common.json` 现在是空骨架，格式与政治完全一致：

```json
{
  "title": "常识背诵",
  "updated": "2026-11-01",
  "intro": "弹层顶部那行说明",
  "categories": [
    { "id": "cs01", "name": "法律常识", "group": "法律" }
  ],
  "cards": [
    {
      "id": "cs01-001",
      "cat": "cs01",
      "text": "我国现行宪法是 ____ 年颁布的。",
      "answers": ["1982"],
      "note": "",
      "source": "宪法"
    }
  ]
}
```

规则：

* `text` 里的 `____`（四个下划线）是填空位置，`answers` 按出现顺序一一对应，**数量必须相等**；
  没有填空的卡片也能存在（纯知识点，背诵模式下就是一段话）。
* `cat` 必须命中某个 `categories[].id`，否则分类名会直接显示成 id。
* `group` 是弹层里的二级分组标题，可以留空串（落到「未分组」）。
* 用户在 App 里改过的分组 / 收藏存在 settings 表里，覆盖资产里的默认值；换资产文件不会冲掉用户编排。

常识那份资产可以照 `tools/build_recite_asset.cs` 的产物格式手改一份。
**政治的卡片库 `recite_politics.json` 已经删了**：政治页改读统一库 `recite_library.json`
（`tools/build_politics_recite.cs` 直接产出），卡片流只剩常识在用。

来源是超格 App 里买的「【早自习】2027 政治理论背诵手册礼包」→「核心知识带背」分组，
抓取用 `chaoge-recite` 技能（MuMu 模拟器 + uiautomator2，UI 抓取，因为卡片内容不落库）：

```bash
# 1) 抓：把「核心知识带背」每节的背诵卡片存成 course_content/<课程名>.txt
python scripts/extract_chaoge_recite.py --out-dir F:/Code/Android/fenbi/tmp/recite_early/course_content
# 2) 灌：重建 cg01..cg20 分类并保留「精编考点」
dotnet run tools/build_recite_asset.cs -- --src tmp/recite_early/course_content --refresh-cg
```

节数会随课程更新变化（18 节 → 20 节 → …），以 App 里分组行右侧那个展开箭头 `▾` 为准，
不要按「20节」这段文字写死。当前 20 节 / 1118 张，加精编 86 张共 1204 张。

### 政治的另一来源：思维导图大盘点（2026-11）

这本册子是 39 页扫描版导图（前 3 页内容流损坏，实际内容是书页 02–37 共 36 个主题，
归成 10 个板块：党建、新思想与现代化、经济与金融、民主法治、教育科技文化、民生与社会、
安全与国防、生态、外交、党史与经验）。

**2026-11 之后它已经并进统一库**：导图原文行成为大纲里的条目（按 `context.depth` 缩进），
`assets/recite_mindmap.json` 只在「鸟瞰导图」里还用得上（画布要树形结构），P1 会把它也切到统一库。

* 入口：政治大纲页 `⋯` →「鸟瞰导图」（原独立页 `MindMapFragment`）
* 列表：顶部按板块筛选，列表一个板块一段，一段里一页书一张卡（书页号 / 章节名 / 分支与要点数），
  点卡片进图形化导图页
* 导图页：**按导图画，不是缩进大纲**——中心主题在左、分支向右展开，节点是圆角块，
  父子之间连贝塞尔曲线（`MindMapGraphView`）。同层同列（列宽取该层最宽节点），
  纵向按子树高度排，父节点对齐子节点块的垂直中心；折叠的分支不参与布局，
  所以一页 60 多条要点不会一次全画出来
* 交互：双指缩放、单指拖动、点节点折叠 / 展开（折叠的节点右侧挂一个「+N」小圆点，
  N 是被藏起来的后代数），双击在「适应屏幕」和 1:1 之间切；底部还有
  适应屏幕 / 展开全部 / 只看主干
* 默认展开到第 3 层（中心主题 → 分支 → 要点），再往里折起来
* 整句原文、不挖空，用于通读 / 朗读
* 书页 02 下半部的「党建思想内涵连线」做成配对自测：左提法 / 右内涵（每次打开打乱），
  点选配对，对了变绿锁定，错了提示一次。入口在导图页底部（有连线的主题才出现）

数据格式 `assets/recite_mindmap.json`（v2，树形）：

```json
{
  "version": 2,
  "title": "政治理论思维导图大盘点",
  "updated": "2026-11-15",
  "intro": "…",
  "sections": [
    {
      "id": "s01",
      "name": "党的建设与全面从严治党",
      "topics": [
        {
          "id": "mm02",
          "page": 4,
          "label": "书页 02",
          "name": "五中全会3-4 · 党性与从严治吏",
          "nodes": [
            {
              "text": "五中全会 3",
              "children": [{ "text": "增强党性是全面从严治党的根本性任务。把加强党性修养作为终身课题" }]
            }
          ],
          "pairs": [{ "left": "坚持党的领导", "right": "是中国特色社会主义最本质的特征" }]
        }
      ]
    }
  ]
}
```

* 层级只由 `children` 表达（v1 是扁平 `outline[{level,text}]`，深层一多就说不清缩进到底代表哪一级）
* `page` 是源 PDF 页码（书页号 + 2），`label` 是书页号；`id` = `mm` + 书页号
* `pairs` 是人工校准的连线题：坐标还原会把「提法 ↔ 内涵」错落成父子关系，
  所以配对关系单独存一份（`tools/mindmap/pairs.json`），渲染时做配对卡而不是节点
* 坐标（x/y）留在源数据里，不塞进资产——App 的图形化导图按树自动排版（列式布局），
  不用 OCR 坐标；只有将来要还原原书版式时才从源 json 取 x/y

生成流程（两步，各管一段）：

```bash
# ① OCR 带坐标的文本框 -> 树形结构（产出仓库根目录的 json + md，供校对）
dotnet run tools/build_mindmap_tree.cs

# ② 树形结构 + 人工校准的 pairs.json -> App 资产
dotnet run tools/build_mindmap_asset.cs                      # 写资产
dotnet run tools/build_mindmap_asset.cs -- --check            # 只校验
dotnet run tools/build_mindmap_asset.cs -- --updated 2026-11-15
```

源数据：`政治理论思维导图大盘点-树形结构.json`（按 OCR 文本框坐标还原的树，含 x/y）
+ `tools/mindmap/pairs.json`（人工校准的配对；连线题被坐标还原错落成父子，正确关系单独存）。

第 ② 步脚本会重算板块 / 主题 / 节点数并打印（当前 10 / 36 / 1105），主题名里的「书页 04 · 」
前缀会被拆成 `label` + 干净标题，重跑幂等。

`tools/build_mindmap_recite.cs` 是早期「每 6 行切一张卡」的灌库脚本，已被上面的方案取代，
只作留档，不要再跑（跑一次会把删掉的 mm 分类重新写进政治背诵资产）。

## 五、界面

三页（词库 / 政治大纲 / 常识）共用同一条顶部「词库 / 政治 / 常识」切换，切换只是 `replace`
一个 Fragment，底部导航仍高亮「背诵」。骨架统一：白底 + 左对齐页标题 + 三段切换 + 一行筛选 / 进度，
下面才是内容区。

**词库**：搜索框 + 分类胶囊 + 标签筛选，列表按拼音首字母分组，长按进多选删除。

**政治（大纲页 `ReciteOutlineFragment`）**：

* 顶栏：睁眼图标（**遮答预览**，默认关）、`A中` 字号、`⋯`（继续上次背诵 / 重置已背进度 / 鸟瞰导图）；
* 进度行：`已背 12 / 2216` + 「只看未背」胶囊；
* 列表：一级分支 = 内容标签（默认全折叠，点行展开），分支内按 `source` 插一行灰色来源小字，
  再下面是条目行——卡片点行揭示答案、点右侧 40dp 圆点标记已背；导图行按 `depth` 缩进；
* **默认整篇可读**，一进来就满屏下划线没法读。要自测就点睁眼打开遮答，遮的是资产预算好的
  挖空区间（引号术语 / 数字 / 顿号并列 / 末分句），点行揭示、再点收起；没区间的单句短语不遮；
* 字号三档（15 / 17 / 19sp）与背诵页共用同一份设置。

**聚焦背诵（`ReciteDrillFragment`）**：大纲里点导图行、或长按任意一条进来，一条一屏。

* 范围按「这一条属于哪一块」自动定：卡片 = 同一讲（31 组、中位数 33 条）；导图行 = 同主题（中位数 27 条）；
* 标题是这一组的名字（讲名 / 主题名），面包屑是当前这条的标签——同一讲跨几个标签很正常，切条时会变；
* 轻点揭示 / 收起、长按按住偷看（松手即藏）、左右滑切条、顶栏 `A中` 字号；
* 底部只有两个决策：`还不熟` 跳过不标记、`背会了` 标已背并进下一条；
* 背到底 → 卡片原地换成小结（共几条 / 已背几条），可「再背一遍」或「回大纲」；
* 每切一条写 `lib_last`，大纲 `⋯ → 继续上次背诵` 落回这条。

**常识（卡片流）**：

* 顶栏：睁眼图标、字号；筛选行：范围胶囊 + 只看重点 + 「第几张 / 共几张」；
* 卡片左右滑切题（到头循环），长按看答案、轻点常显 / 收起；背诵模式下答案常显；
* 范围弹层：全部考点 / 只看重点 + 按拼音排序的分组与分类，分组可增删改、长按课程移组；
* 还没内容时给的是「这块内容还在整理，后续版本更新」，不是「这个范围还没有考点」，
  免得让人以为是筛选筛空了。

**鸟瞰导图**：从政治大纲页 `⋯` 进，页面骨架同样是三段切换（高亮政治）+ 板块胶囊 + 主题卡，
点卡进 `MindMapGraphDialog` 看图形导图；返回回大纲页，不再回旧的政治卡片页。

## 六、网页 / MCP 编辑内容

背诵的三块内容（词库 / 政治 / 常识）都能在电脑上改；思维导图作为第四块，能浏览也能改。入口有两个：

> 政治这一块改的是**统一库本身**（`/api/library`，落 `filesDir/recite_library_user.json`），
> 网页上「政治理论大纲」一栏就是 App 政治页的内容：按标签分段、点开改正文与答案。
> 旧的卡片库已经退场，编辑器不再列它。

* **网页编辑器**：局域网编辑器顶栏「题库 / 背诵」切换（见 [12 局域网编辑器](12-局域网编辑器.md) 的「背诵词库编辑」一节）；
* **MCP 工具**：`qbank_recite_subjects / recite_get_cards / recite_save_cards / recite_reset` 和
  `qbank_words_search / word_save / word_delete`（见 [13 MCP 接入](13-MCP接入.md) 与 `tools/qbank-mcp/README.md`）。
  其中卡片读写工具现在只服务常识：政治改成统一库大纲后不是卡片了，`qbank_recite_subjects` 会把
  `library` 那条单列出来，改它只能走网页编辑器的「政治理论大纲」。

思维导图在网页上是「板块 → 主题 → 树」的浏览 + 编辑：行内改字、加同 / 子节点、
缩进反缩进、上下移动、删节点，配对题也能改左右两栏。整份保存同样要过手机确认，
落在 `filesDir/recite_mindmap_user.json`（和背诵词库同一套闸门），「重置为内置」就是删它。

持久化口径（关键的一点）：两块背诵内容的内置资产（`assets/recite_*.json`）**只读**，
网页 / AI 的修改落在 `filesDir/recite_<subject>_user.json` 的**用户覆盖文件**里，
`ReciteRepository` 读内容时覆盖文件优先、且按 `lastModified` 自动失效缓存；
「重置」就是删覆盖文件。保存走与发布同一套确认闸（网页等手机点确认，AI 带 key 直写），
服务端保存前校验：`____` 数量与 `answers` 数量一致、卡片 / 分类 id 唯一、`cat` 引用存在。
App 里的收藏、范围、背诵进度存在 settings 表、按卡片 id 关联，改内容 / 重置都不会冲掉它们
（删掉的卡收藏自然失效，加回来的卡 id 相同就还能接上）。
