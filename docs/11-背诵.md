# 11 背诵（词库 / 政治 / 常识）

底部导航第二项叫**背诵**（`tab_recite`），这一项下面分三块，靠页面顶部那条
「词库 / 政治 / 常识」切换互相跳转，切换只是 `replace` 一个 Fragment，底部导航仍高亮「背诵」。

| 段 | 页面 | 内容来源 | 说明 |
|---|---|---|---|
| 词库 | `WordListFragment` | `assets/builtin/words.csv` + 用户导入 | 成语 + 实词同表，搜索 / 分类 / 标签筛选，按拼音首字母分组 |
| 政治 | `ReciteFragment(POLITICS)` | `assets/recite_politics.json` | **原「考点背诵」**，内容与交互不变，只是改了名字与入口 |
| 常识 | `ReciteFragment(COMMON)` | `assets/recite_common.json` | 刚建好的空页，资产填进去就有了 |

## 一、为什么是这三块

原来底部导航第二项叫「词库」，里面塞了三页（词库 / 成语 / 考点背诵）。成语和词库本来就是
同一批数据（成语只是 `category = idiom` 的那部分），分成两页反而要多点一次；而「考点背诵」
是政治理论的背诵卡，跟词库没有共同点。所以：

* 成语汇总页（`IdiomListFragment` + `IdiomRepository` + `assets/idioms.json`）**并进词库页**：
  它的搜索框挪到词库页顶部，归类浏览由标签筛选承担，词典数据本来就和内置词库重复。这几个文件已删除。
* 考点背诵改叫**政治**，和新增的**常识**并列，两者共用同一套背诵界面。

## 二、政治与常识的区别只有三样

界面、手势、背诵模式、分组编排全部复用 `ReciteFragment`，差异收在 `ReciteSubject` 里：

```kotlin
enum class ReciteSubject(val id: String, val asset: String, @StringRes val titleRes: Int) {
    POLITICS("politics", "recite_politics.json", R.string.title_recite_politics),
    COMMON("common", "recite_common.json", R.string.title_recite_common),
}
```

打开页面时用 `ReciteFragment.newInstance(ReciteSubject.COMMON)`，页面从 `arguments` 里取
`recite_subject` 还原，取不到默认政治（老入口不会崩）。

### 存库 key

| 项 | 政治 | 常识 |
|---|---|---|
| 重点收藏 | `recite_favorites` | `recite_common_favorites` |
| 上次范围 | `recite_category` | `recite_common_category` |
| 上次背到哪张 | `recite_last_card` | `recite_common_last_card` |
| 分组编排 | `recite_group_layout` | `recite_common_group_layout` |
| 字号 / 背诵模式 | `recite_font_level` / `recite_mode`（两块共用） | 同左 |

政治沿用**老版本不带前缀的 key**，升级上来原有的收藏、范围、进度都还在。

## 三、常识内容怎么填

`assets/recite_common.json` 现在是空骨架，格式与政治完全一致：

```json
{
  "title": "常识背诵",
  "updated": "2026-11-01",
  "intro": "弹层顶部那行说明",
  "categories": [
    { "id": "cs01", "name": "法律常识", "group": "法律" }
  ],
  "cards": [
    {
      "id": "cs01-001",
      "cat": "cs01",
      "text": "我国现行宪法是 ____ 年颁布的。",
      "answers": ["1982"],
      "note": "",
      "source": "宪法"
    }
  ]
}
```

规则：

* `text` 里的 `____`（四个下划线）是填空位置，`answers` 按出现顺序一一对应，**数量必须相等**；
  没有填空的卡片也能存在（纯知识点，背诵模式下就是一段话）。
* `cat` 必须命中某个 `categories[].id`，否则分类名会直接显示成 id。
* `group` 是弹层里的二级分组标题，可以留空串（落到「未分组」）。
* 用户在 App 里改过的分组 / 收藏存在 settings 表里，覆盖资产里的默认值；换资产文件不会冲掉用户编排。

政治那份资产由 `tools/build_recite_asset.py` 从抓取的课程文本生成，常识同理，可以照那个脚本改一份。

## 四、界面

* 顶栏：背诵模式开关（睁眼图标）、选择范围、字号 A小/A中/A大；下面一行是当前范围 chip 与「第几张 / 共几张」。
* 卡片：左右滑动切题（到头循环），长按显示答案、轻点收起；背诵模式下答案常显。
* 范围弹层：全部考点 / 只看重点 + 按拼音排序的分组与分类；分组可新建 / 改名 / 删除，长按课程可移组。
* 常识还没内容时给的是「这块内容还在整理，后续版本更新」，不是「这个范围还没有考点」——
  免得让人以为是筛选筛空了。
