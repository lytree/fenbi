# 12 局域网编辑器（电脑上加题）

手机 App 里起一个 HTTP 服务，同一 Wi-Fi 下的电脑用浏览器打开就能**直接改手机里的题库**。
不用导 Excel、不用连数据线、不用装任何电脑端软件。

> 入口：记录页右上角齿轮 → **设置 → 在电脑上加题 → 局域网编辑器**。

---

## 一分钟流程

1. 手机和电脑连同一个 Wi-Fi（公司网络若开了「AP 隔离」，两台设备互相看不见，改用手机热点最快）。
2. 手机进「设置 → 局域网编辑器」，点 **启动服务**。建议顺手在「访问密码」里设一个密码（见下一节）。
3. 把页面上那个地址（形如 `http://192.168.1.23:8777/`）敲进电脑浏览器。地址里没有口令，服务重启也不会变；
   **设了访问密码的话，先输一次**，之后一周内这台电脑不用再输。
4. 左边选一组（App 首页最上面那一层标题），或者「＋ 新建一组」，然后加题 / 改题。
5. 点右上 **发布到 App**（Ctrl+S），**再拿起手机点一下「确认发布」**——回到手机，试卷列表里就是新的内容。

> 两层门：**登录**挡住同一 Wi-Fi 下顺手打开地址的人（读也看不到）；
> **手机确认**挡住电脑上的误操作（登录了也改不动库，只有手机点了才写）。
> AI 客户端（MCP）配了 `QBANK_KEY` 才能直接发布，见 [13 MCP 接入](13-MCP接入.md)。

## 访问密码

手机页面上的「访问密码」卡片：

| 操作 | 结果 |
|---|---|
| 输入 + **保存密码** | 立刻生效。网页打开先要输这串，`/api` 全部要求登录态；AI 配置里的 `QBANK_KEY` 也用同一串，**服务重启不用重新复制** |
| **清除密码**（要确认一次） | 回到「谁都能打开」：同一 Wi-Fi 下任何人都能看题库、改草稿；发布 / 删除仍要手机确认 |
| 留空不设 | 同上，默认就是这个状态 |

- 密码**至少 4 位**，建议 6 位以上；不是账号体系，就是挡一下隔壁工位，别拿它当网银密码。
- 登录态存在浏览器 Cookie 里（HttpOnly，7 天）；手机改密码、或服务重启都会让旧登录失效，需要重新输。
- 连错 8 次会锁 1 分钟，4 位数字也经不起一直试。
- 密码存在 App 私有目录的 `SharedPreferences`（`lan_editor`），系统备份会带走，换机恢复不用重设。
- 忘了密码？在手机上重新设一个就行——服务器只认当前这串，旧的自然作废。

服务由前台服务托着：手机锁屏、切到别的应用都不影响，通知栏常驻一条地址；
要关掉就点页面上的「停止服务」或通知栏里的「停止」。

## 网页上能做什么

| 区域 | 能做的事 |
|---|---|
| 左栏 | App 里现有的所有组（标题），带「几卷 · 几题 · 缺几道答案」；新建一组；刷新列表；悬停出现「删除」（要手机确认） |
| 工作表列表（编辑区左侧） | 一个工作表 = App 里的一份卷，竖着列出并带各卷题数；点一条切卷，双击改名，`✕` 删除，`＋ 工作表` 加一份卷。列表里**没有「全部」**这种把多卷并在一起的选项——App 那边也是一份一份卷开的 |
| 题目卡 | 行测题型（一级 / 二级）、作答形式 / 难度、题干、选项（A–H，点字母圈设为答案）、答案、解析、地区 / 来源 / 年份 / 分值 / 得分点。题目列表里按住卡片左侧 `⠿` 可拖动排序：拖到某题上 / 下半区 = 插到它前 / 后（落进材料组就跟着共用该材料），拖到材料组头上 = 并入该材料 |
| 材料组 | 连续几道题填同一段材料时自动成组，**只在组首显示一个输入框**，改一次全组同步（对应 App 的「材料逐行重复」规则）；输入框下方有「图文排版」按钮，把图和文字摆成并排 / 上下 |
| 材料模式 | 工具条左侧切到「材料」：一则材料成一个块，上面是放大的材料编辑区（带排版预览 / 插图），下面是它带的全部小题，块头「＋ 加小题」直接加在组尾并自动共用材料（详见 [14 材料多题编辑模式](14-材料多题编辑模式.md)） |
| 分组板 | 工具条左侧切到「分组」：左边一栏是未分组题目，右边是一则则材料块。把题拖进材料块 = 并入该材料（落到组尾，保持卷面连续）；拖回左边 = 移出材料；拖到某道题上 = 插到它前 / 后；整组按住 `⠿` 可拖动排序。勾选多道题后可批量并入材料组 / 移出分组 / 删除；点题目卡选中该题，右侧卷面预览同步显示题干、选项、答案、解析和图片 |
| 工具条 | 搜索（题干 / 材料 / 答案 / 解析…）、筛选（状态 / 作答形式 / 一级题型 / 二级题型，可叠加）、批量粘贴、新题 |
| 右栏 · 卷面预览 | 尽量按 App 答题页的版式渲染：材料通栏、题型小标（一级 · 二级）、圆形选项徽标、答案高亮；点任意一块跳到左边那道题，左边选中哪题预览也滚到同一题并高亮。面板左边缘可拖动改宽度（280px 起，给编辑区留够位置），窄窗口下这个宽度同样作用于浮层 |
| 右栏 · 校验 | 本地实时检查：题干为空、选项不足两个、答案不在选项范围、题干重复、材料组被拆…点一条跳到那道题 |
| 右栏 · 版本 | 这一组每次被覆盖之前的存档，能回滚、能删存档（每组留最近 20 版） |
| 手机页 · 访问密码 | 设 / 改 / 清除网页登录密码；设了之后 AI 配置里的 `QBANK_KEY` 也用同一串 |
| 手机页 · AI 接入 | 页面底部给出带当前地址与 `QBANK_KEY` 的 MCP 配置，一键复制给 Claude Desktop / Cursor（见 [13 MCP 接入](13-MCP接入.md)） |

**题型按行测分两级**：一级复用「科目」列（`行测·资料分析` 归一成 `资料分析`），二级复用「知识点」列
（`资料分析·增长量` 归一成 `增长量`），不新增字段、不改手机端表结构。题目卡与卷面预览都显示「一级 · 二级」，
二级为空时显示「一级 · 未分类」；两级都没填的题退回显示作答形式（单选 / 多选 / 判断…）。
输入时一级、二级带常用候选（言语理解与表达 / 数量关系 / 判断推理 / 资料分析 / 常识判断及其常见二级题型），也可自由填写。

**筛选**分四档，可叠加使用：状态（有问题 / 缺答案 / 带图 / 材料组）、作答形式（单选 / 多选 / 不定项 / 判断 / 填空 / 主观）、
一级题型、二级题型。一级、二级都从当前这卷的科目 / 知识点归一后现算，顺带列「未填一级」「未填二级」；
选了某一级后，二级下拉只列这一级下的二级。下拉选项后面都带着当前这卷的题数，选完工具条上会显示「筛出 N / M 题」，
旁边「清除筛选」一键复位；切卷、换组时筛选项自动清空（题型每卷各算各的，留着上一卷的选项只会筛出空列表）。

**批量粘贴**是把一段现成的题目文本变成题的入口，认这套写法：

```text
1. 下列句子中，没有语病的一项是（  ）
A. 第一项内容
B. 第二项内容
C. 第三项内容
D. 第四项内容
答案：B
解析：这里写解析

2. 下一题题干……
A. ……
答案：AC
```

题与题之间用 `1.` `2.` 编号，或者空一行；`答案：` `解析：` `材料：` 做前缀；
两个以上答案字母自动记成多选题。**没有选项的块会被丢掉**——App 目前只答选择题。

**图片**：题干 / 选项旁边的「图」按钮选文件，或者直接在文本框里 `Ctrl+V` 贴截图。
图按**试卷组编号**分目录存：`filesDir/lan_editor/images/<组编号>/xxx.png`，题目里写成
`images/<组编号>/xxx.png`，发布时再换成手机上的绝对路径（App 的材料渲染认绝对路径，换机备份也跟着走）。
还没发布的新组没有编号，图片先落 `images/draft/`，下次打开这一组时自动搬进正式目录。
右栏「资源」页签能看这一组的全部图片、引用次数、未引用和引用缺失的图，也能上传 / 换图 / 删图。

**数据源**：只有一种——手机上的题库。页面通过手机端局域网服务读写，顶栏按钮是「发布到 App」，
点完还要在手机上点一次「确认发布」才真正落库；手机没连上就直接报「连不上题库」，
不再退到本地文件。**明暗**：顶栏右上角那枚方形小章切白天 / 夜间，选择记在浏览器 localStorage，
没选过时跟系统 `prefers-color-scheme`。

**图文排版**：材料组输入框下方有一排「左图右文 / 右图左文 / 图在上 / 图在下 / 多图并排」。
选中要和图排在一起的那段文字再点，会自动包成 `:::figure` 块（写法见 [02 试卷格式规范](02-试卷格式规范.md)）；
没选中就插一段可用的样板。右栏卷面预览按同一套规则渲染，预览什么样，手机上就是什么样。

## 本地草稿（关掉页面也不丢）

- **自动保存**：改动停下来 700ms 就写一份到浏览器 localStorage，另外每 30 秒兜底再存一次；
  关标签页、切到后台（合盖子）时立刻落盘。顶栏「未发布」旁边会显示「已自动保存 时:分」。
- **不设过期时间**：只要没发布、也没主动丢弃，草稿一直在，隔几周回来打开仍然会问「接着上次改？」。
- 草稿只存在你这台电脑的浏览器里，不占手机空间，也不会上传；换浏览器/无痕窗口/清站点数据就没了。
- 发布成功、从手机上重新打开这一组、或启动提示里选「取消」，草稿会被清掉。
- 草稿是**内容快照**，不是版本：它只有一份（当前这一组），要按时间翻旧版看「版本存档」那一节。

## 发布到底做了什么

点「发布到 App」是**两步**，不是一步：

1. **网页只负责登记**：服务端先校验（同名组要不要覆盖、题干 / 选项够不够），
   通过后**不写库**，只登记一条「待确认发布」，网页上出现「等手机上点确认」的浮层。
2. **手机上点确认才落库**：手机「局域网编辑器」页面会弹确认框（App 不在前台时是一条通知），
   点「确认发布」才按下面的规则重导这一组。10 分钟没人理自动作废，网页上点「撤回请求」也能收回去。

真正的写入规则没变——「发布」= **按标题重导这一组**，和导入一个 Excel 是同一个动作：

| 网页上的东西 | 落到哪儿 |
|---|---|
| 组标题 | `paper_sets.title`（App 首页那一层标题） |
| 一张工作表 | 一份卷 `papers`（卷名 = 表名） |
| 一道题 | `questions` + `paper_questions`（按卷面顺序，题号连续） |
| 材料组 | 组内每道题的 `material` 都写同一段文本 |

两条要记住的口径：

1. **同标题 = 覆盖**。已有同名组时发布会先弹确认，确认后那一组旧卷连同**作答记录**一起被替换掉
   （这是「同一个文件重导一次」的既定行为，不是这次新加的）。
   **但内容不会白丢**：覆盖前会把旧的那一版自动存进「版本」，右栏点「版本」就能翻回来或回滚。
   题目是按 id 原地更新的，所以**收藏、笔记、错题标记都还在**；卷描述和限时会从旧卷继承回来，
   不会被写字成一串默认值。存档写失败时发布会直接中止（不会「没备份也照写」）。
2. **不达标就整批不写**。题干为空、选择题不足两个选项这类硬错误会让发布失败，
   网页上会列出「哪张卷第几题、什么问题」，改完再发——不会悄悄少几题。

想保住旧的作答记录，就别用同一个标题：改个组名发布，旧的留着。
作答记录本身不参与版本存档——能救回来的是题目内容，不是谁做过、做对了几道。

## 版本存档（改错了能回滚）

| 什么时候存 | 存什么 | 存到哪 |
|---|---|---|
| 覆盖发布之前 | 这一组当时的全部卷与题目（图片是 `images/<组编号>/…` 相对路径） | `filesDir/lan_editor/versions/<时间戳>-<随机数>.json` |
| 回滚到某一版之前 | 同上——先给「现在」也存一版，滚错了能再滚回来 | 同上 |

- 每组只留**最近 20 版**，更旧的自动清掉；删存档只删文件，不动题库。
- **回滚同样要手机确认**：网页上点「回滚到这一版」只是发请求，手机点了才会替换内容。
- 版本列表按当前组名查。改了组名还没发布之前，看到的是新名字下的（通常是空的）；
  发布之后旧名字那一组的版本仍在，改回名字就能看到。
- 回滚落回**你当前打开的这一组**（按组 id），不会因为快照里存的是旧标题就多出一组。
- 存档点是**发布 / 回滚这两个边界**，不是每次编辑：改十道题只会在发布时留一版；
  编辑过程中的历史没有逐次记录（撤销/重做也没有），只有上面那份最新草稿。要留中间态就中途发布一次。

## 图片存储与迁移（按组编号）

- **存储口径**：`filesDir/lan_editor/images/<组编号>/<文件名>`，题目里写 `images/<组编号>/<文件名>`；
  发布时换成绝对路径入库。还没发布的新组先落 `images/draft/`。
- **打开即迁移**：网页打开一组时，题目里引用到的老平铺图（`images/x.png`）和导入试卷包留下的
  绝对路径，会复制一份进本组目录，网页上的引用同步改成组目录；点发布后路径落库。
- **手动整理**：右栏「资源 → 整理图片」会把**这一组**所有被引用的散图复制进组目录，
  并直接改写题库里的图片路径（不用先发布）。有未发布改动时会先拦下，避免库里改完、
  网页草稿还指着旧路径。接口 `POST /api/images/migrate`，body `{ setId }`；
  `setId=0` 表示全库整理（MCP / 调试脚本用）。
- **不改内容、不删源文件**：迁移只动题干 / 材料 / 解析 / 选项里的图片路径，答案、难度、收藏都不碰；
  源图保留，因为网页草稿、其他组、历史版本可能还在引用。没人引用的散图无从判断归属，
  留在原处（报告里的 `orphans`）；删除整组时才会清掉该组目录。
- **历史版本**：快照里存的是相对路径，回滚发布时照常解析；如果原图已经不在了，
  预览会显示成掉的图，和普通缺图一样。

## 安全边界

- 服务只在**你按下启动**之后存在，停服务或杀掉 App 就结束，不会开机自启。
- **第一层：访问密码（可选，建议设）**。设了之后网页先要登录，`/api` 下的所有接口都要会话 Cookie；
  没设就是整站开放——同一 Wi-Fi 下的设备打开地址就能看题库（含作答记录）、改草稿、传图。
  登录态 7 天，手机改密码或服务重启都会让旧登录失效。
- **第二层：写库必须手机点确认**。就算登录了，发布、回滚、删除也只登记一条请求，
  手机「局域网编辑器」里弹框点「确认」才真正动库——10 分钟没人理自动作废，网页上也能撤回。
  电脑误点、同一个浏览器里别的标签页乱调接口，都改不动题库。
- **AI（MCP）走请求头口令**：`QBANK_KEY`，请求时放进 `X-Lan-Key`。
  设了密码就是那串密码（重启不变），没设则是每次启动生成的随机码；都**不出现在任何 URL 上**。
  带对了就直接发布，不用每步都点手机（否则一次批量导入要点几十次）。
  没配 key 的 MCP 也能连（未设密码时），只是发布同样要等手机确认。
- 端口默认 `8777`，可在页面上改（1024–65535）。

风险提示：没有密码时，同一 Wi-Fi 下的其他人打开地址就能看题库内容。公用网络（酒店、咖啡馆）
加完题就把服务停掉，或者先把访问密码设上；不想让旁人看到，就用手机热点。

## 接口一览（写脚本 / 调试时看）

都返回 JSON。认证分两种，按优先级：

1. **请求头 `X-Lan-Key: <密码>`** —— AI / 脚本用，同时具备「读」和「直接发布」权限；
2. **登录会话 Cookie**（`POST /api/login` 拿）—— 网页用，能读能改草稿，但发布仍要手机确认；
3. 没设密码时都不需要，但发布同样走手机确认。

未登录且不在白名单的 `/api` 请求返回 `401`，网页端会自动刷新回登录页。

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/login` | `{ password }`：登录，成功回 `Set-Cookie: le_session=…`（HttpOnly，7 天）；连错 8 次锁 1 分钟 |
| GET | `/api/papers` | 组列表（带卷数 / 题数 / 缺答案数） |
| GET | `/api/paper?id=<组 id>` | 一组展开：`sheets[].questions[]`，`type` 用 `truefalse` 表示判断题 |
| POST | `/api/publish` | `{ title, replace, sheets:[{name, questions:[…]}] }`；同名组且 `replace=false` 时返回错误让前端确认；无 key 时回 `needConfirm` |
| GET | `/api/publish/status?id=<请求 id>` | `pending / approved / rejected / expired`；`approved` 时 `result` 是发布结果 |
| POST | `/api/publish/cancel` | `{ id }`，网页撤回发布请求 |
| POST | `/api/image?name=<文件名>&setId=<组编号>` | 请求体是二进制图片，返回 `{ path: "images/<组编号>/xxx.png" }`；带 `replace=<路径>` 时原地换图 |
| GET | `/api/resources?setId=<组编号>` | 这一组目录下的图片：`files[]` 含 `path / name / size / mtime` |
| DELETE | `/api/resource?p=<相对路径>` | 删一张图；只认 `images/…`，删完题目里的引用会显示成掉的图 |
| POST | `/api/images/migrate` | `{ setId }`：把散图整理进 `images/<组编号>/` 并改写题库路径；`setId=0` = 全库，返回 `moved / reused / missing / orphans` 统计 |
| GET | `/api/img?p=<路径>` | 取图；只允许资源目录里的 `images/…` 相对路径 |
| GET | `/api/meta` | 端口 / 地址 / 应用标识 / `publishNeedsConfirm` |
| GET | `/api/versions?title=<组名>` | 这组的历史版本（新的在前），只给摘要 |
| GET | `/api/records?setId=<组 id>` | 这一组的作答记录：分数、正确率、状态（只读） |
| GET | `/api/record?id=<记录 id>` | 一次作答的逐题明细：用户答案、标准答案、对错、得分（只读） |
| POST | `/api/version/restore` | `{ id, setId, title }`；`setId` = 当前打开的组，回滚落回它；无 key 时回 `needConfirm` |
| POST | `/api/version/delete` | `{ id }`；只删存档文件 |
| POST | `/api/delete/request` | `{ setId }`，返回 `{ requestId, title, detail, ttlSec }`；**不会删任何东西** |
| GET | `/api/delete/status?id=<请求 id>` | `pending` / `approved` / `rejected` / `expired`，网页靠它轮询 |
| POST | `/api/delete/cancel` | `{ id }`，网页撤回请求 |

字段与 [02 试卷格式规范](02-试卷格式规范.md) 完全一致，只是从「列」换成了 JSON key。

> 早先还有一个只在 `pnpm dev` 下存在的 `/local/*` 接口组（直接读写仓库里的 JSON 试卷包）以及左栏的
> 「手机题库 / 本地试卷包」切换。这套「本地试卷包」模式已经整块删掉：网页只连手机，
> 路径统一为 `/api/*`，没有第二套数据源。

## 开发与构建

前端在 `tools/webeditor/`，**Vue 3 + TSX（禁止模板，没有 `.vue` 文件）**，
编译器用 [vue-jsx](https://vuejsx.dev/)（Rust / Oxc，插件 `vue-jsx/vite`），
`tsconfig` 里的 `jsxImportSource` 必须写 `vue-jsx`：

```bash
cd tools/webeditor
pnpm install       # 包管理统一用 pnpm（锁文件是 pnpm-lock.yaml）
pnpm dev           # 本地开发：接口指向 /api，需要手机端服务或自己搭 mock
pnpm test          # vitest + jsdom 冒烟：打开一组 → 加题 → 发布，断言发出去的 JSON
pnpm build         # 产物直接写进 app/src/main/assets/webeditor/
```

> 用 pnpm 12 时，`pnpm install` 默认**不允许依赖跑安装脚本**（会报 `ERR_PNPM_IGNORED_BUILDS`）。
> 这里需要放行 esbuild（Vite 打包要它的平台二进制），已经写在 `pnpm-workspace.yaml` 里：
> `allowBuilds: { esbuild: true }`——这是 pnpm 12 的新位置和键名，不是以前的 `package.json → pnpm.onlyBuiltDependencies`。

构建产物**要提交**（`app/src/main/assets/webeditor/`），这样改了 Kotlin 也照常 `./gradlew assembleDebug`，
不需要先跑 Node。`node_modules/` 已在 `.gitignore` 里。

后端在 `app/src/main/java/com/lytree/qbank/ui/laneditor/`：

| 文件 | 职责 |
|---|---|
| `LanEditorServer.kt` | 标准库 `ServerSocket` 手写的 HTTP/1.1 服务：请求解析、路由、静态资源；登录页与会话校验；写接口按 `X-Lan-Key` 决定直发还是登记确认 |

## 常见问题

**电脑打不开地址**：先确认在同一个 Wi-Fi；再试手机热点。
公司/校园网常见「AP 隔离」（同一 Wi-Fi 下设备互不可见），这时只能用热点。
Windows 第一次连会询问网络类型，选「专用网络」，否则防火墙可能拦掉。

**页面打不开 / 一片空白**：确认地址里的端口和手机页面上显示的一致（默认 8777），
并检查服务是不是还在跑。地址不带口令，不用再拼 `?t=`。

**打开是一张「请输入访问密码」的登录页**：手机上设过密码。输对就进，输错会提示；
忘了就回手机重设一个。没设密码却看到登录页，说明 App 里还留着旧密码，去「访问密码」里清除。

**输对了密码仍然被弹回登录页**：浏览器禁用了 Cookie，或者用的是无痕窗口（关掉就丢）。
换普通窗口 / 允许 Cookie 再试。

**改密码后网页突然跳回登录页**：这是故意的——改密码会让所有已登录的浏览器重新登录。

**发布报「已经有同名的组」**：这是防手滑的确认，点「覆盖发布」会替换整组（含作答记录），
但旧内容会先存进「版本」，右栏能回滚。

**点了发布 / 删除，网页一直转圈**：它真的在等手机。手机上会弹确认框（App 没在前台会收到一条通知），
点「确认发布」/「确认删除」才执行，点「不」就作废。网页上点「撤回请求」也能收回去。

**手机上没弹确认框**：先看「局域网编辑器」页面的服务是不是还在跑——服务停了请求就全作废；
再看通知权限有没有给（Android 13+ 不给通知，只有把 App 打开到那一页才会弹）。

**AI 报 401 /「口令不对」**：手机设了访问密码，但 MCP 配置里的 `QBANK_KEY` 不是那串密码；
没设密码时则是服务重启后随机码变了。回 App 的「AI 接入」重新复制配置。

**发布报「第 3 题：选择题至少要 2 个有内容的选项」**：网页上那道题的选项还空着，补上再发。

**图片在网页上预览不出来**：先看题目里的路径是不是 `images/<组编号>/…`。
老数据里的平铺 `images/x.png` 和导入包留下的绝对路径，会在打开这一组时自动搬进组目录；
图片文件本身没了的话会列在右栏「资源 → 引用找不到文件」里。

**换端口**：先「停止服务」，改端口，再「启动服务」；正在跑的时候端口是只读的。
