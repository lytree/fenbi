# 14 · 材料多题编辑模式（局域网编辑器）

> 状态：**已实施**（2026-11-13）。只改 `tools/webeditor` 前端；手机端表结构、发布接口、
> App 的 `PaperStructure` 判定口径全部不动。

---

## 1. 目标

在电脑网页编辑器里，以**一片材料 → 多道小题**为单位编辑，而不是在平铺的题目卡里
上下翻找「组头」和组尾。

```
材料 1 ─┬─ 材料正文（只维护一份）
        ├─ 小题 1
        ├─ 小题 2
        └─ 小题 3
```

## 2. 现状与问题

材料组是**派生**出来的：卷面上连续、`material` 文本 `trim()` 后完全相等的题才算一组
（`store.groupsOf`），列表里只在组首渲染一个组头输入框。

| # | 问题 |
|---|---|
| 1 | 组头夹在题目卡之间，材料里有表格 / 图文时输入区被压得很小，长材料不好写 |
| 2 | 加小题要先滚到组尾「在下方插入一题」，再点「沿用上一题材料」，两步都容易插到组外 |
| 3 | 这则材料带了几道题、材料同步到了哪几题，只能靠题号在列表里数 |
| 4 | 「材料」明明是这一块的主对象，界面却以题目为主 |

## 3. 视图设计

入口在编辑区工具条左侧的分段控件：

```
[题目 3] [材料 1] [分组 1]   搜索…   状态…   题型…   一级题型…   二级题型…
```

- **题目**：保持原有平铺列表（`QuestionList`），行为不变；
- **材料**：新增 `MaterialList`，按卷面顺序输出两类块：

```
[按材料成块编辑：上方改材料，下方加 / 改小题…]

┌ 材料 1   第 2–3 题 · 2 题共用            [排版预览] [＋ 加小题]
│ ┌──────────────────────────────────────────────────────┐
│ │ 材料正文（大输入框，随内容自动长高）                    │
│ └──────────────────────────────────────────────────────┘
│ 图文排版  左图右文 右图左文 图在上 图在下 多图并排  插图
│ （可选）排版预览：按 App 材料渲染口径渲染 :::figure / 表格 / :::chart
│ ── 小题 2 道 ──
│ [题目卡 2]
│ [题目卡 3]
└

┌ 独立题目   第 1 题 · 无材料
│ [题目卡 1]
└
```

- **分组**：新增 `GroupBoard`，拖拽题目分配材料组、批量多选（详见 [12 局域网编辑器](12-局域网编辑器.md)）。
- **独立题目不隐藏**：没材料的题夹在原来的卷面位置，顺序不乱；
- **搜索 / 筛选仍然生效**：块内只列命中的小题，块头显示「筛出 k 题」；一组全被筛掉就不出块；
- **材料块按材料编号**（材料 1、材料 2…），编号只在当前视图内计算，不落库。

## 4. 交互规则

| 操作 | 行为 | 数据 |
|---|---|---|
| 改材料 | 组内每道题的 `material` 同步成同一段文本；输入过程中只写题上文本，**失焦时才重算分组** | `setGroupMaterial(start, text, false)` |
| ＋ 加小题 | 在**组尾**插入空白题，`material` 直接复制组内文本 | 仍逐题存 |
| 移出材料组 | 题目卡里原按钮，清空该题 `material` | 组按连续规则自动裂开 |
| 沿用上一题材料 | 无材料题目卡里原按钮 | 与上一题并组 |
| 排版预览 | 只读渲染，用的是右侧卷面预览同一套 `renderMaterial` | 不写库 |
| 插图 / Ctrl+V | 上传到手机 `filesDir/lan_editor/images/`，插入光标处 | 与列表模式相同 |
| 上移 / 下移 / 复制 / 删除 | 题目卡原有动作；跨越组边界后按连续规则重算分组 | 不变 |

## 5. 数据口径（刻意没变）

- 不新增字段、不改 `LanEditorStore.kt`、不改发布接口；
- 材料仍然**逐行重复**：发布时组内每道题的 `material` 都写同一段文本，
  App 端继续用「连续 + 全文相等」派生材料组；
- 组只能由卷面上连续的题构成，所以「＋ 加小题」只追加在**组尾**，
  不提供「插到组中间」——插中间会让卷面顺序和题号对不上；
- 空材料 = 独立题：把材料正文清空会让这一组解散（与列表模式一致）。

## 6. 边界情况

| 场景 | 处理 |
|---|---|
| 筛选只命中组内部分题 | 块头显示「筛出 k 题」；改材料仍同步组内全部题 |
| 组里只有 1 题 | 仍是材料块，块头显示「1 题共用」 |
| 组内题目上移 / 下移出组 | 按连续同材料规则重算，可能裂成两块 |
| 清空材料正文 | 编辑过程中块与输入框保留（分组延后到失焦），可以接着重写；失焦后仍为空才解散、回到独立题 |
| 整卷没有材料 | 材料模式只剩独立题块，等价于题目列表 |
| 切卷 / 换组 | 当前视图保留；筛选项按原行为清空 |

## 8. 测试

| 用例 | 断言 |
|---|---|
| 切到材料模式 | 1 个材料块 + 1 个独立题块；块头「第 2–3 题」；组内 2 张题卡；材料输入框为共用文本 |
| ＋ 加小题 | 组内变 3 题；发布 JSON 里新题 `material` 与组内一致 |
| 改材料正文 | 发布 JSON 里组内两题 `material` 同步更新，独立题仍为空 |
| 切回题目模式 | 材料组头仍只在组首出现一次，题目卡数量不变 |
| 清空材料正文 | 输入框不消失，可继续重写；失焦后为空才解散成独立题 |
| 删空后不失焦直接发布 | 发布后按最新内容重算分组，不留「看不见的材料组」 |
| 连续输入 | 输入框不会被旧值回写，发布出去的是最后一段文本 |
| 改材料 / 题干 | 右侧卷面预览实时更新；删空材料时右侧按数据立即去掉材料，左侧块保留到失焦 |
| 材料块排版预览 | 随材料编辑实时更新（含表格渲染） |
| 点小题卡 | 右侧卷面预览滚到并高亮同一题 |
