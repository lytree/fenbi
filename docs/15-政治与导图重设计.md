# 15 政治与思维导图重设计（v2 方案）

> 目标一句话：**把「政治」做成能读、能背、能自测的一本书，而不是两个各管一半的功能页。**
> 本文是设计稿，落地时按第 8 节的 P0 / P1 / P2 分期提交；P0 不改资产，P1 才动数据。

## 1. 现状诊断（先看清问题再推翻）

### 1.1 数据：导图不是导图，是 OCR 碎片

对着 `assets/recite_mindmap.json` 实测（36 主题 / 1105 节点）：

| 指标 | 实测值 | 说明 |
|---|---|---|
| 根节点数 | 263 | 平均每页 7 个「中心主题」 |
| 深度分布 | d0=263 / d1=600 / d2=210 / d3=31 / d4=1 | **78% 的节点只有 0~1 层**，形态是「一行 + 一个子行」 |
| 节点正文长度 | 中位数 22 字，p90 49 字 | 一条一句话，本身就是可背的最小单位 |

再看具体内容，"根"经常是**被 OCR 框切的单字**：

```
mm20 教育强国 · 立德树人
  根：教 / 育 / 强国 / 教 / 育        ← 书页上的「教育强国」被逐字切开
  根：分配 / 制 / 度 / 业 / 就        ← 「分配制度」「就业」
```

结论：**当前资产没有真实的树结构**。它是一页书的多行原文，被 OCR 的坐标框强行连成了父子。任何"画成图"的方案都会被这份数据拖死——画布上看到的是一堆两列小方块，看不出任何结构。

### 1.2 呈现：画布是给「看结构」的，不是给「背」的

`MindMapGraphView` 的实现没问题，问题在形态选择：

* 节点文字 12sp、`textMaxWidth = 190dp`，一页 50 条要缩到 **0.3 倍**才能塞进竖屏 → 实际字号约 4sp，读不了；
* 撑满屏幕靠「双指缩放 + 单指拖动」，这是地图手势。通勤路上单手做不了；
* 折叠能救，但一折叠就只剩「教 / 育 / 强国」这种碎片根，等于没有信息。

### 1.3 结构：两套内容、两个页面、两条进度

| | 政治（背诵卡） | 思维导图 |
|---|---|---|
| 内容 | 1204 张填空卡，29 个分类 | 36 个主题，10 个板块 |
| 交互 | 左右滑切题、长按偷看、星标 | 画布缩放、点节点折叠、配对自测 |
| 入口 | 背诵 Tab → 政治 | 政治顶栏一颗图标 → `replace` 整页 |
| 进度 | 记住"上次第几张" | 无 |

切换要退出重进，两边的筛选/字号/背诵模式各管各的。用户想"从导图看到某个点，再背它对应的卡"，做不到。

### 1.4 缺的三件事

1. **读不了**：政治卡没有"连续阅读"形态，1204 张只能一张张滑，看不到章节脉络；导图有脉络但不能读。
2. **背不了**：导图只能"看"，没有把一条条过一遍的机制；卡能背但脱离上下文。
3. **找不到 / 记不住**：两个库合计 2300+ 条，没有搜索；进度只到"上次那张"，没有"这个主题我背到哪了"。

## 2. 设计原则

1. **竖向文字流优先**。手机是竖屏，背诵是线性行为。任何需要缩放/横拖才能读的版式，一律降级为辅助视图。
2. **一条一屏**。数据实测中位数 22 / 44 字，正好一条一屏；不为"版面丰富"把多条挤在一起。
3. **上下文常驻**。背一条时，永远能看到它属于哪个板块、哪个主题、哪条分支（面包屑），这是导图相对纯卡片唯一不可替代的价值。
4. **两种模式，一套数据**：通读（看全文）与自测（遮答案）随时切换，不复制内容、不另建资产。
5. **不为了好看砍可用性**：字号、行距、点击区先满足"躺着背、走路背"，动画克制。

## 3. 新结构

政治只剩**一种形态**：一棵以标签为分支的导图大纲。原来「卡片流 / 导图」两套界面合并成一套。

```
背诵 Tab
└── 词库 / 政治 / 常识            （现有三段切换，不动）
    └── 政治
        └── 大纲（导图形式，唯一列表）
              ▾▍新思想                                533     ← 一级 = 标签，可折叠
                   超格 · 政治理论考情介绍+新思想导论         ← 来源小字（视觉分段，不可折叠）
                   习近平新时代…是____相结合的重大成果        ← 卡片：正文一行，点行揭示
                   党的建设2 · 组织/作风/纪律/反腐            ← 导图主题，同样只做来源小字
                     ▍一体推进不敢腐、不能腐、不想腐…         ← depth 0，带主色短条
                       重在「一体」，也难在「一体」           ← depth 1，每级再缩进
        └── 点导图行 / 长按任一条 → 聚焦背诵（一条一屏，挖空/揭示/按住偷看）
```

树是**自然形成**的，不是又造一套分组：

| 层 | 来源 | 说明 |
|---|---|---|
| 一级分支 | `tags[0]`（主标签） | 18 个内容标签，取代 10 板块 + 29 分类；没打上标签的归「未归类」 |
| 来源小字 | `source` | 卡片是「超格 · 第几讲」，导图是「板块 / 主题」取主题名；只做阅读分段 |
| 缩进 | `context.depth` | 导图原树的层级，每级 14dp；卡片没有层级，从一级起 |

关键变化：

* **取消 `MindMapFragment` 与「考点卡 / 导图」分段**：政治页只有这一个大纲（旧导图页降级成 `⋯` 里的「鸟瞰导图」）；
* **取消卡片流**（左右滑切题那套）：卡片正文变成大纲里的一行，挖空处点开揭示，逐条过的动作交给聚焦背诵；
* **画布退出主路径**（`MindMapGraphView` 代码保留，入口收进 `⋯`）；
* 已落地：**大纲页**（`ReciteOutlineFragment`，政治页本体）与**聚焦背诵**（`ReciteDrillFragment`，见 4.2）。

## 4. 页面规格

### 4.1 大纲页（已落地，`ReciteOutlineFragment`）

```
┌ 政治理论                          已背 128/2216   A中  ⋯
├ ▾ ▍新思想                                    128 / 533
│      超格 · 政治理论考情介绍+新思想导论
│      习近平新时代…是____相结合的重大成果            ○
│      党的建设2 · 组织/作风/纪律/反腐
│      ▍一体推进不敢腐、不能腐、不想腐…              ●
│        重在「一体」，也难在「一体」                ○
├ ▸ ▍经济                                          292
├ ▸ ▍党的建设
└ ▸ 未归类                                         281
```

* **一级分支 = 标签**（19 行，含「未归类」）：16sp 加粗 + 主色竖条 + 右侧 `已背 / 总数`，整行点击折叠；
* **默认全部折叠**：一支展开就是几百条，先给一张目录；折叠状态落库 `lib_fold`，第二次进来照旧；
* **来源小字**：`source` 收成一行 11sp 灰色小字（导图取「板块 / 主题」里的主题名），**不可折叠**——它是阅读节奏，不是又把分组加回来；
* **条目行**：15sp（随字号档 15/17/19），卡片 `____` 未揭示时是一段浅灰下划线，**点行揭示**（答案主色加粗 + 淡底），再点收起；导图行按 `depth` 每级缩进 14dp，`depth=0` 带主色短条并加粗；
* 右侧 40×40 点击区 `○/●` 标记已背，**点正文不标记**（阅读时防误触）；
* 顶栏：睁眼图标 = 答案常显（与背诵页共用 `recite_mode`）、`A中` 循环字号、`⋯` 里放「重置已背进度 / 鸟瞰导图」；
* 进度行：`已背 128 / 2216` + 「只看未背」胶囊（开着一支里只剩没背过的；整支背完的分支不占位）；
* 滚动位置落库 `lib_scroll`，切到词库再回来不会跳到开头。

> 「来源小字」这一层是刻意的降级：原来的分组不再有层级，但一屏里连续 40 条如果没有任何分隔，读起来找不到落点。

### 4.2 聚焦背诵（`ReciteDrillFragment`）— 已落地

从大纲里**点导图行 / 长按任意一条**进入，起点就是那一行，一条一屏：

```
← 新思想                                 12 / 42
▬▬▬▬▬▬▬▬▬░░░░░░░░░░░░░░░░░░░░░
┌────────────────────────────────────┐
│ 习近平新时代中国…同______相结合的    │
│ 重大成果。                          │
│          轻点揭示 · 长按偷看         │
└────────────────────────────────────┘
[ 还不熟 ]                    [ 背会了 ]
```

* **范围按「这条内容所属的那一块」自动定，不用调用方传一堆参数**：
  * 卡片 = **同一讲**（`source`）。实测 31 组、中位数 33 条、最多 93 条。原本想用「标签 + 来源」，
    结果 44% 的组只剩 1~2 条（`谋划十五五` 这种一讲的内容本来就横跨好几个标签），太碎；
  * 导图行 = **同一主题**（36 个主题，中位数 27 条）；
  * 只有一两条时也不放宽到整个标签：宁可背两条就结束，也别让人点进来发现还有 500 条；
* **标题 = 这一组的名字**（讲名 / 主题名），**面包屑 = 当前这条归在哪个标签**——标签是横切分类，
  同一讲里跨几个标签很正常，切条时它跟着变，正好说明「标签不是文件夹」；
* **三种显示状态**：
  * 遮答（默认）：卡片的 `____` 显示成灰色下划线；导图行按资产里预算好的 `cloze` 区间遮（见 6.4）；
    **没有 `cloze` 的（单句短语）整条显示**——遮住就一点线索都没有，不如让人直接读；
  * 轻点揭示 / 收起；顶栏睁眼（`recite_mode`）打开则答案常显；
  * 长按偷看：按住显示、松手隐藏，和旧卡片流同一套手感（`GestureDetector` + `ACTION_UP/CANCEL` 收尾）；
* **底部两个按钮就是全部决策**：`还不熟` 跳过、不标；`背会了` 标已背并进下一条（这条已经背过时按钮显示「下一条」，不重复写库）；
* 左右滑 = 上 / 下一条；到最后一条再往后 → 卡片原地换成小结（`共 42 条 · 已背 40 条`），给「再背一遍 / 回大纲」，不另开页面；
* 每切一条写 `lib_last`，大纲 `⋯ → 继续上次背诵` 直接落回这条；
* 挖空渲染抽在 `ReciteCloze`，大纲页与这一页共用一份，避免两处走形。

> **大纲页默认不遮**（`lib_blind` 默认关）：那是「读」的地方，一进来满屏下划线没法读，
> 用户只会以为页面坏了。要自测就点顶栏睁眼打开遮答预览，点行揭示——和背诵页是两个开关。

### 4.3 连线配对（保留，未落地）

`pairs` 仍在资产里（导图主题的「提法 ↔ 内涵」）。计划在聚焦背诵滑到该主题末尾时出现一颗「配对自测」，交互沿用现有 `MindMapPairs`（左点提法、右点内涵、对了两边变绿）。它是导图主题的附加动作，不再单独占一页。

### 4.4 搜索（P2，但接口先留）

* 一个 `SearchFragment`，输入框 + 结果列表（只有一种结果，不再分「卡 / 图」两组）；
* 命中词高亮，行尾标出来源标签；
* 点结果 = 回大纲并**自动展开到该行**（参数 `focusId`）；
* 数据量 2216 条，内存里 `contains` 足够，不需要索引库。

### 6.2 结构

```json
{
  "version": 1,
  "title": "政治理论",
  "tags": [
    { "id": "xinsixiang", "name": "新思想", "kind": "topic",  "count": 550 },
    { "id": "chaoge",     "name": "超格手册", "kind": "source", "count": 1171 }
  ],
  "items": [
    {
      "id": "cg01-001",
      "kind": "card",
      "text": "习近平新时代中国特色社会主义思想是……同____相结合、同____相结合的重大成果…",
      "answers": ["中国具体实际", "中华优秀传统文化"],
      "source": "超格 · 政治理论考情介绍+新思想导论",
      "tags": ["xinsixiang", "chaoge"]
    },
    {
      "id": "m-mm04-3.1",
      "kind": "line",
      "text": "坚持惩前毖后、治病救人，深化运用监督执纪“四种形态”",
      "cloze": [{ "start": 21, "end": 26 }],
      "source": "党的建设与全面从严治党 / 习近平党建思想",
      "tags": ["dangjian", "daotu"],
      "context": { "topic": "mm04", "name": "习近平党建思想", "path": "3.1", "depth": 1 }
    }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `kind` | `card`（带挖空与答案）/ `line`（导图原句） |
| `tags` | `tags[0]` 是主标签，也就是大纲的一级分支；来源标签 `kind=source`，与内容标签分开显示 |
| `context` | 只对 `line` 有，做大纲的二级分支和面包屑；**不是分组**，不参与筛选 |
| `cloze` | 只对 `line` 有，遮答用的挖空区间（`[start, end)`，UTF-16 下标，和 Java/Kotlin 的 `String` 下标一致）；**缺省表示这条不遮** |
| `id` | 卡片沿用原 id，导图是 `m-<主题>-<路径>`；进度按 id 存，树不变得以保留 |

### 6.3 标签口径

* 内容标签 18 个：分组名能给出主标签就用分组名（精编分类、导图主题），给不出（`谋划十五五`、`系列讲话`、`重要文件` 这些来源切片）就交给正文关键词；
* **主标签必须命中 ≥2 个不同特征词**（2026-11-15 收严）：只沾一个词的多半是「经济发展」「思想教育」这种跨领域常用词，交给邻接继承；
* 补充标签：同样 ≥2 个特征词才加，最多 2 个；
* 关键词表按「只有这一点特征」来收：「教育」收成「教育强国 / 教育科技 / 立德树人 / 思政课」，避免「思想教育」把反腐卡判成教育科技；
* 挖空把关键词挖走的（「思想建设的首要任务是____」），先看同分组左右各 2 条，再退回整组投票（组内同质率 ≥55%）；
* 碎片根（`教` / `育` / `强国`）**没有自动合并**：拼错一个词比留个碎片更糟，报告里列了清单等人工确认。

### 6.4 挖空预计算（已落地）

`ComputeCloze()` 在 `build_library.cs` 里跑，只处理 `line`：卡片自带 `____` + `answers`，不需要。

原则只有一条：**宁可少挖，绝不切词**。遮罩切在词中间（「马克思主__义政__治家」）比不遮更糟，
所以规则全部对在天然边界上，按顺序取，每条最多 3 个区间（实测平均 1.09 个）：

| 序 | 规则 | 例 |
|---|---|---|
| 1 | 中文引号里的提法（2~20 字） | 规范「**一把手**」职责权限 |
| 2 | 数字：年份 / 百分比 / 届次 | 到 **2035 年**、**20%** |
| 3 | 同一分句内的顿号并列（≥3 项、每项 2~10 字）→ 挖第 2 项往后 | 坚持科学决策、**民主决策、依法决策** |
| 4 | 兜底：遮**最后一个完整分句**（前面 ≥5 字当提示、被遮 ≥5 字） | 增强党性是全面从严治党的根本性任务。**把加强党性修养作为终身课题** |

结果：1045 条导图行里 **510 条有挖空（48.8%）**，区间全部落在词/分句边界上，无越界无重叠。

剩下 51.2% 是单句短语（「全面从严治党关键在从严治吏」），**不遮**——遮住就没法猜，
整条显示让人直接读更诚实。App 端因此不做任何自动挖空判断：规则算错一次就挖在词中间，
比不遮更糟，一律交给构建期（Kotlin 侧 `ReciteCloze.line()` 只认区间）。

### 11.2 条目怎么切

* 每节从 1 重新编号，`N.` 起一条，缩进更靠左的续行接回上一条；`【对比】`/`【记忆方法】`/`（判断）`/`①②③` 另起一行；

  1434 条里 267 条有挖空（379 个空），其余是纯陈述条目——这本教材本身大多没有可挖的强调标记，硬猜会把句子挖碎。
