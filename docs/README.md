## 三条常见路径

1. **只想做题** → [01 快速开始](01-快速开始.md)，导入页「载入示例题库」先跑一遍。
2. **想把自己的题库导进来** → 下载 [templates/题库模板.xlsx](../templates/题库模板.xlsx) 照着填，字段含义查 [02 题库格式规范](02-题库格式规范.md)。
3. **材料里有折线图/柱状图** → [03 题库包](03-题库包.md)，或者用 `:::chart` 直接在文本里写数据。
