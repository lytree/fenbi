# 粉笔 App 考试界面与交互逻辑调研

> 调研时间：2026-10-23 ｜ 来源：网络搜索（产品体验报告、官方帮助中心、软件站教程等）

## 一、整体导航结构

- 底部固定四个 Tab：**首页 / 课程 / 题库 / 我**，日常操作集中在题库与个人中心。
- 首次打开引导选择考试类型（公务员、事业单位、教师等），首页据此定制内容。
- 题库页：按「考试类别 → 科目 → 模块（如国考-行测-判断推理-图形推理）」三级筛选进入练习。

## 二、组卷设置页（开始刷题前）

| 设置项 | 说明 |
|---|---|
| 题量 | 默认 15 题，可选 5～30 题；智能组卷/自定义组卷可按模块分别设置题量 |
| 练习模式 | **练习模式**（答题后立即出解析）与**考试模式**（全真计时、不即时判分、交卷后统一出分） |
| 出题范围 | 可勾选是否包含收藏题、错题；顺序/乱序作答 |
| 计时 | 不限时 / 正计时 / 倒计时（考试模式固定总时长） |

## 三、做题页（核心界面）

### 3.1 顶部栏
- 左：**关闭(X)** —— 退出并保存进度（中途退出可续做，已进入考试流程则退出后需重新设置才能改题量）
- 中：**计时器**（"不限时"/正计时/倒计时）+ 试卷标题（如"资料分析题库包（标准结构）（4题）"）
- 右：**下载**、**交卷(√)**、**答题卡(列表图标)**、**更多(...)**（含草稿纸、夜间模式等）

### 3.2 题目区块
- 题号 + 题型标签（"单选题"/"多选题"），右侧一排图标：**书签(标记) / 铅笔(笔记) / 星星(收藏)**。
- 材料题：材料卡片带"材料"标签，右上角"弹出材料"——**上下分块独立滑动，用户可自定义两块占比**（模拟纸质试卷翻页感）；资料分析支持**分屏**（材料区 + 题目区）。
- 草稿纸：半透明浮层出现在最上方，可随意书写，**可拖动、可延伸**大小。
- 选项：圆形 A/B/C/D 字母 + 选项内容，点击即选中。
- 长按题目文字可添加笔记，笔记同步至错题本/个人中心。

### 3.3 切题交互
- **单题模式**：上下滑动（或左右滑动）切换题目；解析页有"上一题/下一题"导航。
- **分页模式**：一屏纵向多题连续排布（如材料题包，见 docs/fenbi-package-exam.png）。
- 疑难题可**标记后跳过**，回头再做；答题卡上显示标记状态。

### 3.4 判分逻辑（练习 vs 考试模式的关键区别）
- **练习模式**：点选答案 → 立即判对错 → 选项变色（正确绿/错误红）→ 展开解析（考点说明 + 选项对比 + 视频解析入口）。
- **考试模式**：选答案只记录不判分；顶部严格倒计时，**到点自动交卷**；建议"难题标记跳过、按模块限时"；中途可暂停但模考暂停会失去意义。

## 四、答题卡（校对答案入口）

- 从做题页顶部第三个按钮（列表图标）进入，半屏底部弹层（见 docs/ui 截图中的"答题卡"）。
- 题号网格，按状态着色：**已作答（蓝）/ 未作答（灰）/ 已标记（橙/含角标）/ 当前题（高亮）**。
- 点击任一题号直接跳转该题。
- 底部主按钮：**「交卷并查看结果」**——点击后交卷进入练习报告。

## 五、成绩报告（练习报告）

- 顶部大号**得分**（如 0.0），下方一排统计：**正确率 / 答对题数 / 总题数 / 总用时**（如 1分钟）。
- 分模块正确率列表（言语/判断/数资/资料等），用于定位薄弱模块。
- 模考另出：**全省/全国排名、击败率、模块得分分布**；当天或次日出分。
- 入口：**「全部解析」**按钮或直接点击题号进入单题解析。

## 六、解析页

- 内容自上而下：题干 → **你的作答 vs 正确答案**对比（选项着色）→ 详细解析 → **考点** → **来源**（年份/试卷）→ 笔记区（可"添加笔记"）。
- 右上角星星：收藏/取消收藏（toast "已收藏"）。
- 解析底部有**「问 AI」**按钮：自动带入题干+作答情况进入粉笔头对话，追问"为什么选C""同类题怎么举一反三"。
- 错题本/收藏夹内错题有**「让 AI 讲讲」**入口，做错因归因。

## 七、错题本与收藏

- 入口：首页/练习页右上角**田字格菜单 → 我的错题 / 我的收藏**。
- 错题本：按考试类型/科目/题型/掌握状态筛选，时间倒序；支持"近一周/全部历史"。
- **交互式重做**：点击选项重新作答，答对自动移出错题本并计入"已掌握"；答错保留并高亮正确答案+易错点。重做不限次数。
- 收藏夹：手动收藏的经典题/易错题，再点星星取消。

## 八、模考大赛（全真考试场景）

- 流程：App 内报名 → 提前 10 分钟进考场 → **统一开考、严格限时（行测 120 分钟）** → 到点自动交卷。
- 特点：当期新编模拟卷（非真题）、同期考生同步作答、有排名与解析讲评；申论需拍照上传手写答案。
- 网页版答题界面：左侧题目、右侧答题卡，支持题目标记、跳题、自动计时。

## 九、不同类型题目的布局样式

### 9.1 通用题目卡片结构（所有客观题共用）
```
┌──────────────────────────────────────┐
│ 1.  [单选题]          🔖(标记) ✏️(笔记) ⭐(收藏) │  ← 题号 + 蓝色题型标签 + 右侧三图标
│                                      │
│  题干文字（可含图片/表格/公式）          │
│                                      │
│  Ⓐ  选项内容                          │  ← 圆形字母 + 内容，默认竖排一列
│  Ⓑ  选项内容                          │
│  Ⓒ  选项内容                          │
│  Ⓓ  选项内容                          │
└──────────────────────────────────────┘
```
- 选项排版：短选项支持 **1/2/4 列 flex 自适应**（网页版验证：列距 18px、行距 0.5em）；长选项自动回落单列。
- 选项含图时图片限幅（约 140×100），图形推理四个选项常排 **2×2 网格**。
- 判色（练习模式）：正确=绿、错误=红、你的错误选择=红、正确答案=绿高亮。

### 9.2 各题型差异
| 题型 | 标签样式 | 选项/作答区 | 特殊交互 |
|---|---|---|---|
| **单选题** | 蓝色圆角标签"单选题" | A/B/C/D 圆圈字母+文字，竖排 | 点选即定，再点其他选项可改选 |
| **多选题/不定项** | 标签"多选题" | 同单选，选中态加深（可反选取消） | 需全对才得分；不定项选中 1 个即可确认提交 |
| **判断题** | 标签"判断题" | 仅"正确/错误"两项，样式同单选 | 等同二选一单选 |
| **材料题（言语/常识）** | 材料块带"材料"标签，位于题目卡顶部 + 多道子题 | 材料整块随卷面滚动；同一材料只在组首渲染一次 | 右上角"弹出材料"→左右分屏看材料 |
| **资料分析** | 材料含图表/表格 | 同上分块；另提供**分屏模式**（横屏/大屏材料+题目左右分列） | 图表内嵌材料卡，点击可放大 |
| **图形推理** | 题干为图组 | 选项为四个图形，2×2 网格 | 点击图形即选中 |
| **申论主观题** | "问题"按钮展开作答区 | 三种录入：**文字输入 / 语音录入 / 拍照上传**（方格答题纸识别率最高） | "保存草稿"+"右上角√"交卷；AI 智能批改出诊断报告 |

### 9.3 模式对布局的影响
- **做题模式 vs 背题模式**：背题模式选项下方直接展示答案与解析，不作答。
- **练习模式**：选项点击后立即锁定判色、解析内联展开在选项下方。
- **考试模式**：选项仅呈选中态（蓝色圆圈填充），无判色无解析；题干行标记图标使用频率最高。

## 十、对本项目的可借鉴要点

结合 docs/ 中现有截图（我的题库、题库详情、组卷、答题卡、成绩报告、资料分析分屏已实现），粉笔原版交互可补充的点：

> **2026-10-23 更新：以下 1～8 已全部落地实现**（详见 README 功能列表与本次代码改动）：
> ① 练习/考试双模式（练习模式即时判分）② 答题卡四态标色 ③ 题目三件套图标 ④ 材料题交互
> ⑤ 练习报告 + 分模块正确率 ⑥ 中途退出续做（进度落库 + 倒计时接续）⑦ 错题重练闭环 ⑧ 题型差异化布局（多选反选、判断题二项）。
>
> **同日二次校准（以真机截图为准）**：材料块改为**题目卡顶部通栏、白底整块展开**（不做固定高度内滚、不显示拖动手柄），
> 同一材料组只在首题渲染一次；表格列宽自适应整屏宽度（列多时缩字号，不横向裁切）；
> 手机端「弹出材料」进左右分屏（左栏约 40%、右栏连续题目列表）；文字选项统一单列——均与粉笔实机一致。
> 收藏持久化（favorites 表）也一并补齐。尚未实现：主观题三种录入方式（文字/语音/拍照）——当前版本仍仅支持选择题。
>
> **第三次校准（2026-10-23，以 6 张模考卷真机截图为准）——卷面形态整体改版**：
> ① **白底通铺**：答题卷面从「一张张圆角白卡 + 16dp 卡间距」改为**整页纯白、题与题之间一条 0.5dp 细线**（`fb_sheet_bg` / `fb_question_divider`），
> 单题浏览、多题浏览、分屏右栏三处同步；单题浏览一屏一题、下方没有下一题，不画这条线。
> ② **模块说明卡**：新增「资料分析 (20题)」那一块——浅蓝渐变圆角卡 + 模块名/题数 + 该模块官方说明文案，
> 按 `subject` 聚合、只在组首题出现一次（`ModuleHeaders`）；分屏右栏不重复显示。
> ③ **题目三图标**：标记从书签改为**细线星**（`ic_fb_star_outline`），与右侧收藏星区分；笔保持不变。
> ④ **字号/徽标**：题干 17→16sp、行距 6→7dp，选项圆 40→32dp、字母 14→16sp，更接近截图里「徽标只比字母大一圈」的比例。
> ⑤ **顶栏标题**：17sp 加粗 → 13sp 常规，窄屏不再被挤成「sa…」（`fb_bar_paper_title`）。
> ⑥ **分屏页**：顶栏只留返回 + 计时（`FbTitleBar.setTimer()`，新增的计时胶囊默认隐藏、不影响其他页面），
> 左栏材料白底无外框，右栏题号接整卷序号（106./107./108.）。底部操作条保留——参考应用那两栏是纯阅读态，
> 但本项目分屏页要能交卷/调答题卡，功能优先。

1. **练习/考试双模式**：练习模式即时判分出解析；考试模式倒计时 + 自动交卷 + 交卷后统一判分。
2. **答题卡状态色**：已答/未答/标记/当前四态着色，点击跳题 + 底部"交卷并查看结果"。
3. **题目三件套图标**：标记(跳题用)、笔记、收藏，位于题号行右侧。
4. **材料题交互**：上下分块独立滚动 + 可调占比；"弹出材料"半屏浮层。
5. **练习报告**：得分大字 + 正确率/对题数/总题数/用时四项统计 + 分模块正确率 + 题号直通解析。
6. **中途退出续做**：关闭弹确认，进度本地保存，可继续作答。
7. **错题重做闭环**：重做答对自动移出错题本（"已掌握"）。
8. **题型差异化布局**：短选项 2/4 列排布、图形推理 2×2 网格、多选可反选、判断题二项；主观题三种录入方式（文字/语音/拍照）+ 草稿 + AI 批改。
