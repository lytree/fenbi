> 采集时间：2026-11-21 ｜ 目标形态：桌面浏览器（以 1440×900 为基准）

## 一、这份复刻依据什么做的

### 1.1 实测部分（有据可查）

直接抓取了粉笔官网题库页的前端资源：

```
https://www.fenbi.com/spa/tiku/guide/home/xingce/xingce?labelId=3421
  → //nodestatic.fbstatic.cn/weblts_spa_online/tiku/styles.<hash>.css
```

从该 CSS 里取到的**真实值**（不是估计）：

| 项 | 值 | 出处 |
|---|---|---|
| 主蓝 | `#3c7cfc` | 全表出现 21 次，最高频色 |
| 淡蓝底 | `#eff2fe` / `#ebf1fe` | 次级按钮、标签底 |
| 成功绿 | `#2bc8a0`、淡底 `#f4fcfa` | 判对 |
| 错误红 | `#ff5a5a`、淡底 `#fff7f7` | 判错 |
| 未选选项底 | `#f2f2f5` | 与 App 端完全一致 |
| 浅灰块 | `#f5f7fa` | 统计格、来源块 |
| 正文 / 次要 / 弱文字 | `#32343a` / `#636e92` / `#9ea5bb` | 三级文字 |
| 分割线 | `#dde0e5` | 卡片、栏位分隔 |
| 标记橙 | `#ff7a00` | 角标 |
| 标题字号 | h1–h6 = 22/20/18/16/14/12px（`1rem = 10px`） | `.fbng-h1 … .fbng-h6` |
| 圆角 | 6px / 8px 两个档位 | 按钮、卡片 |

**答题卡三态样式是直接读到的**，这是本次最硬的一条证据：

```css
.ans-btn-answered{ background:#EBF1FE; border:1px solid #3c7cfc; color:#3c7cfc }
.ans-btn-error   { background:#FFF7F7; border:1px solid #FF5A5A; color:#ff5a5a }
.ans-btn-correct { background:#F4FCFA; border:1px solid #2BC8A0; color:#2bc8a0 }
/* 深色模式另有 .ans-btn-answered{ background:#112246 } */
```

也就是说，Web 端答题卡是**淡底 + 同色描边 + 同色文字**，而不是 App 端的实心填充。复刻按这个来。

### 1.2 布局结构部分（多来源一致）

公开可查的使用教程对 Web 端答题页的描述高度一致（4 篇不同站点、互不抄袭的表述）：

> “答题界面**左侧为题目内容、右侧为答题卡**，支持题目标记、跳题作答、自动计时。”
> “交卷后系统立刻生成成绩排名和模块正确率，可直接查看每道题的文字解析与视频解析。”

### 1.3 哪些是推断（重要）

**粉笔的答题页和解析页需要登录才能进入**（手机号验证码 / App 扫码），无法在未登录状态拿到真实 DOM。所以：

- ✅ 色板、字号档位、答题卡三态样式、圆角规范 —— **实测**
- ✅ 页面骨架（左题右卡、顶栏计时与交卷、交卷后看解析）—— **多来源一致描述**
- ⚠️ 具体像素尺寸（顶栏 56px、右栏 336px、材料栏 42%、卡片圆角 12px）—— **按 1440 桌面推断的合理值**，不是实测
- ✅ 解析页的模块清单（答案对照 / 统计三项 / 视频 / 举一反三 / 考点 / 来源 / 笔记）—— 来自本项目 `docs/fenbi-ui/` 的 App 端真机实测，Web 端沿用同一套内容结构

如果要做到 1:1 像素级，需要登录后 `uiautomator`/DevTools 量一遍；本文件的结构已经把尺寸集中写在 CSS 变量和少数几处常量里，替换成本很低。

## 二、两块界面的结构

### 2.1 答题界面（`?q=16`）

```
┌ 顶栏 56px ────────────────────────────────────────────────┐
│ ← 试卷名 / 模块·第16/20题     ⏱ 68:12 / 120:00   ⚑ ★ ✎ ⋯ [交卷] │
└──────────────────────────────────────────────────────────┘
┌ 左：材料 42%（可独立滚动） ┐ ┌ 右：题目（撑满剩余宽） ──────────┐
│ [材料] 2024年某市…        │ │ 16. [单选题]            资料分析 │
│ 正文…                     │ │ 题干…                          │
│ ┌ 指标 │ 绝对量 │ 同比 ┐   │ │ Ⓐ 5.3%          Ⓑ 6.4%         │
│ │ 营业收入 │ 123458 │ 5.4 │ │ Ⓒ 7.2%(已选)    Ⓓ 8.9%         │
│ └───────┴────────┴─────┘   │ │                                │
│                           │ │ ─────────────────────────────  │
│                           │ │ [‹ 上一题] 已答15/20  [下一题 ›] │
└───────────────────────────┘ └────────────────────────────────┘
                                          ┌ 答题卡 336px ─────────┐
                                          │ 答题卡        15/20   │
                                          │ □已答 □未答 □标记      │
                                          │ 常识判断          1–5 │
                                          │ ① ② ③ ④ ⑤            │
                                          │ 言语理解与表达    6–10 │
                                          │ …                     │
                                          │ ▬▬▬▬▬▬▬░░░            │
                                          │ 已答 15/20    标记 3  │
                                          │ [ 交卷并查看结果 ]     │
                                          └───────────────────────┘
```

- **材料题（资料分析）自动切成左右分屏**，材料与题目各自滚动 —— 这正是 Web 端大屏相对 App 的核心优势，App 端要手动进“分屏模式”，桌面端直接常驻。
- 无材料的题（常识/言语/判断）退化为**单栏居中卡片**（最大宽 860）。
- 答题态答题卡只有**三态**：已答（淡蓝描边）、未答（灰底）、标记（右上橙角）+ 当前题（蓝色外环）。**交卷前不显示对错**，和粉笔一致。

### 2.2 解析界面（`?mode=solution&q=16`）

题目区自上而下：

```
✕ 回答错误                                   正确答案 B · 用时约 58 秒
16. [单选题]                                              解析
题干…
Ⓐ 5.3%              Ⓑ 6.4%   ← 绿底绿圈（正确答案）
Ⓒ 7.2%   ← 红底红圈  Ⓓ 8.9%
┌ 正确答案 B ────────┬ 你的答案 C ─────────┐
┌ 58秒 ┬ 62% ┬ C ┐                      ← 答题时间 / 全站正确率 / 易错项
▎解析视频                          06:18
▎文字解析（含【速算】与易错点提示框）
[本题考点…] [开始练习]              ← 举一反三
▎考点  (资料分析) (现期比重) (利润率)
▎题目来源  灰块 + 出处
▎我的笔记  灰块 + [编辑笔记]
✨ 不满意这道解析？可以让 AI 老师针对你的答案「C」讲一遍。 [问 AI]
```

解析态答题卡切换为**对错着色**（绿 = 答对、红 = 答错、灰 = 未答），底部统计变成「答对 11 · 答错 4 · 正确率 73%」。点任意题号直接跳转。

## 三、交互清单

| 交互 | 触发 | 实现 |
|---|---|---|
| 选择答案 | 点选项 / `A B C D` | 单选，可改选，选中态淡蓝底 + 蓝圈 |
| 切题 | `[上一题]/[下一题]` / `← →` | 边界置灰 |
| 跳题 | 点答题卡题号 | 按模块分组定位 |
| 标记 | 顶栏旗标 / `F` | 答题卡右上橙角，可取消 |
| 收藏 | 顶栏星 / `S` | 图标变蓝，第 6 题预置为已收藏 |
| 笔记 | 顶栏笔 / 笔记区块按钮 | 弹窗编辑，保存后回填解析页 |
| 交卷 | 顶栏 / 侧栏按钮 | 二次确认弹窗（显示已答/未答/剩余时间）→ 进解析态 |
| 倒计时 | 自动 | 从 68:12 递减，剩 5 分钟转红，归零自动交卷 |
| 区块折叠 | 点解析区块标题 | 箭头旋转，正文收起 |
| 更多菜单 | `⋯` | 草稿纸 / 题目纠错 / 夜间模式（占位提示） |
| 键盘 | `Esc` 关弹窗 | — |

## 四、和 App 端复刻（`../fenbi-ui/`）的差别

| | App 端（640×360dp 横屏） | Web 端（本次） |
|---|---|---|
| 答题卡位置 | 底部弹出层 / 报告页内嵌卡 | **常驻右侧栏 336px**，始终可见 |
| 材料展示 | 上下分块、可拖拽调占比 | **左右分屏常驻**，各自滚动 |
| 答题卡状态色 | 实心圆 | **淡底 + 同色描边 + 同色字**（官网 CSS 实测） |
| 交卷入口 | 顶部 √ | 顶栏 + 侧栏双入口 |
| 解析页顶栏 | 5 个图标（下载/草稿纸/答题卡/收藏/更多） | 旗标/收藏/笔记/更多 + 交卷 |
| 单位 | dp，1px = 1/3dp | px，`1rem = 10px` |
| 选项字号 | 14sp | 15px |

## 五、已知取舍 / 未复刻

- **练习报告页**没有做（`查看报告` 只给提示）。本次范围是答题 + 解析两屏，报告页在 `docs/fenbi-ui/replica.html` 里已有 App 版可参考。
- **视频解析**只做封面卡（16:9 + 播放键 + 时长 + 星级 + 评论数），不接播放器。
- **草稿纸**、**夜间模式**、**题目纠错**、**PDF 导出**只在菜单里占位。
- **AI 讲解**只做入口样式，不接对话。
- 题目内容为**自编题面**（公考风格，含一段资料分析材料 + 表格 + 一道图形推理 SVG），避免直接搬运真题文本；布局与配色才是复刻对象。
- 窄屏（<980px）隐藏答题卡侧栏 —— 桌面优先，未做移动端抽屉。
