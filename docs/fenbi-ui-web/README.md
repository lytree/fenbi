## 一、这一版是登录后实测的

上一版受限于登录墙，布局靠推断。这次登录后，页面结构**直接用 DOM 量出来**，与推断稿有本质差异：

| | 上一版（推断） | 本版（实测） |
|---|---|---|
| 答题页 | 左侧题目 + 右侧 336px 答题卡常驻栏 | **上下结构**：顶栏 60px + 单栏长列表 + **底部答题卡抽屉** |
| 资料分析 | 左右分屏 | 材料卡与题目**同列上下排**；材料题另有 `APP-MATERIALS` 分屏组件 |
| 答题卡状态 | 淡底 + 同色描边 | 答题时淡蓝描边；**解析时绿/红实心填充** |
| 解析页 | 独立单题页 | **报告 + 解析一体**：得分卡 / 分布图 / 考试情况，往下接逐题解析 |
| 选项统计 | 答案对照条 + 三项 | **四宫格**：正确答案 /（你的答案 或 答题用时）/ 全站正确率 / 易错项 |

https://spa.fenbi.com/ti/exam/solution/1_1_41evkn3?routecs=xingce   交卷后解析

### 2.3 解析页结构

```
顶栏（返回 / 标题 / 设置 / 下载 —— 没有交卷）
├ 左 1fr「得分数据」卡        ├ 右 372px「得分分布图」
│   分数 34px 蓝 + /100       │   正态曲线 + 当前分数标注点
│   总用时；三宫格：最高分 / 平均分 / 已击败考生
├「考试情况」卡
│   行测总计行（共计/答对/答错/未答/用时）+ 各模块行（总题数/答对/正确率/用时）
└ 逐题解析（题目卡顶部 2px 状态条：绿=对 红=错）
    选项着色 → 四宫格 → 折叠「解析」→ 考点胶囊（蓝底白字）→ 笔记
```

**选项三态（解析态）**

| 状态 | 圆圈 | 行背景 |
|---|---|---|
| 正确答案 | 绿色实心 + 白字 | 浅绿 `rgba(43,200,160,.10)` |
| 你的错选 | 红色实心 + 白字 | 浅红 `rgba(255,90,90,.09)` |
| 正确答案但你没选 | **白底 + 绿描边 + 绿字** | 无 |
| 其他 | 浅灰 | 无 |

**四宫格**是动态的：答对时「正确答案 / 答题用时 / 全站正确率 / 易错项」，答错时第二格换成「你的答案」（红色）。

## 三、本版新增：答题记录

粉笔 Web 个人中心没有独立的练习记录页（头像菜单只有课程 / 简历），本版按同一套设计语言补了三块：

1. **记录列表** —— 每条一张卡：试卷名 + 状态标签（已交卷 / 进行中 / 已放弃）、日期、来源、答对 / 答错 / 未答、用时、得分。
2. **记录详情** —— 顶部概要条（得分 / 答对 / 答错 / 未答 / 用时），下面完整复用报告区 + 逐题解析；左上「返回记录列表」。
3. **交卷即入库** —— 答题页「交卷」→ 二次确认 → 自动生成一条记录（含本次作答快照）→ 跳解析页；顶栏「练习记录」可随时回看。

记录详情的解析与交卷后的解析是**同一套渲染**，只是答案来源换成该记录的快照。

| 入口 | 说明 |
|---|---|
| 直接打开 | 答题页（20 题，4 个模块） |

## 六、入口实测（登录墙）

| 步骤 | 结果 |
|---|---|
| `https://www.fenbi.com/spa/tiku/guide/home/xingce/xingce?labelId=3421` | 可访问，188 套卷 |

登录注意：题库子应用不认首页的登录态，需要在题库页自己的弹窗里登录一次（`web-modal-block` → 账号密码 → `.agreement-action-btn` 勾选 → `button[type=submit]`）。headless 自动化时这点踩了很久。

## 七、已知取舍

- 题目内容是**自编公考风格题面**（含一则资料分析材料 + 表格 + 一道图形推理 SVG），不是抓取的真题；复刻对象是版式与交互。
- 得分分布图是 SVG 近似曲线（真实为后端返回的分段人数），标注点位置按分数映射。
- 视频解析、草稿纸、题目纠错、PDF 下载未接，只在菜单里给提示。
- 记录页是**补出来的功能**，粉笔 Web 原站没有对应页面，样式沿用同一套令牌。
- 上一版推断稿 `replica-v1-inferred.html` 保留，便于对比「推断 vs 实测」的差异。
