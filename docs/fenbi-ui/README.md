### 2.3 卡片1 的渐变怎么画的

不是纯线性。取样结果：右上角最蓝（`#CCE5FF`），往左下迅速褪成白。等价写法：

```css
background:
  radial-gradient(92% 96% at 100% 0%,
    rgba(150,197,255,.92) 0%, rgba(196,226,255,.80) 16%,
    rgba(232,244,255,.55) 42%, rgba(255,255,255,0) 74%),
  linear-gradient(180deg,#EFF8FF 0%,#FBFDFF 40%,#FFFFFF 62%,#FFFFFF 100%);
```

Android 对应：`layer-list` 两层 `gradient`，或用 `RadialGradient` + `LinearGradient` 叠两层 View。

### 2.4 交互

- 「答题卡」里的题号**不可点**（这里只是结果展示），只有两个大按钮是入口。
- 「全部解析」走全部题，「错题解析」只走错题（见 §4）。

### 3.3 选项三态（最容易做错的地方）

| 状态 | 圆圈 | 字色 | 说明 |
|---|---|---|---|
| 未作答/其他选项 | `#F2F2F5` | `#868EA8` | 无描边，实心浅灰 |
| 正确答案 | `#2BC8A0` 填充 | `#FFF` | 圆内字母为**白**，不是绿字 |
| 你的错误答案 | `#FF5A5A` 填充 | `#FFF` | 同上 |

### 3.4 解析页顶部的那个 ✕

副标题右侧不是「1/15」而是「✕ 15/15」——**红叉表示这题你答错了**。序号 12.7sp/700 黑，`/15` 11.3sp 灰。

> 本次样本里 15 道题走「错题解析」全是错题，没采到答对态的图标；按同族样式推断应为绿色勾（`#2BC8A0`），实现时留个开关。

## 4. 错题解析 vs 全部解析：差在哪

两者进的是**同一个 Activity**，布局逐像素相同。差别只有数据源：

| | 全部解析 | 错题解析 |
|---|---|---|
| 题序 | 1→15 全量 | 只排错题 |
| 副标题右侧序号 | 1/15 … 15/15 | 跟着当前题在全卷里的题号走 |
| 答题卡 | 15 个题号全列 | **只列错题**（本例 1–10、15，绿题不出现） |
| 其余（材料 / 题干 / 选项 / 答案 / 统计 / 解析 / 视频 / 举一反三 / 考点 / 来源 / 笔记） | 完全一致 | 完全一致 |

答题卡弹层（两处共用同一套样式，只是尺寸不同）：

| | 报告页内嵌卡片 | 解析页弹层 |
|---|---|---|
| 容器 | 白卡，内边距 18dp | 底部 sheet，高 297dp，上圆角 11dp，顶部遮罩 `rgba(0,0,0,.45)` |
| 圆圈 | 32dp | 40dp |
| 列距 | 68dp | 63dp（10 列） |
| 行距 | 24dp | 25dp |
| 标题 | 「答题卡」+ 橙图标 + 三项图例 | 「答题卡」居中 + 右侧 ✕ |

## 5. 复刻文件怎么用

```bash
# 直接双击打开，或
start docs/fenbi-ui/replica.html
```

- 顶部 tab 切三屏；报告页与解析页面板都能滚。
- URL 参数（调试用）：`?raw=1` 去外壳、`&s=report|all|wrong` 指定屏、`&rs=<px>` 报告页滚动位置、`&ps=<px>` 解析面板滚动位置。

### 和现有代码的对应关系

本项目已有 `app/src/main/res/layout/activity_report.xml`，走的是「大分数 + 模块正确率列表」的路子，和粉笔这套不一样。要换成粉笔样式，需要重排成：

1. `activity_report.xml` → 两张卡（考试情况 / 答题卡）+ 固定底部双按钮；
2. 新增 `item_report_stat.xml`（四宫格，四个等宽 Cell + 竖线用 `divider` 或 View 1dp）；
3. `item_report_number.xml` 改成 32dp 圆 + `flexbox` 换行（每行 9 个，`justifyContent=flex_start` + `marginEnd=36dp`，别用 space-between 撑满）；
4. 解析页 `item_analysis_page.xml` 增加：答案对照条、统计三项、视频卡、举一反三、考点、来源、笔记 七个区块；
5. 颜色统一进 `colors.xml`，键名建议 `fb_success / fb_danger / fb_primary_soft`。

## 6. 已知取舍

- **题目内容不是原文**：模拟器上这份卷子是「资料分析」，选项是图表图片；为把文字型选项的三态颜色展示清楚，复刻里用了另一道同卷文字题的排版，选项文案按截图可见部分补全。布局与配色 100% 来自实测，文案仅作占位。
- **卡片1 右上角的 Fb 插画**、**视频封面**、**材料图表**是重新画的近似图形，不是原图资源。
- 报告页卡片 1 的渐变是径向近似，原图可能有图片叠加。
- **「考试情况」整卡首屏完整露出**：原版卡片被滚动视口（y=888）切断，「资料分析」那行描述只露半截、必须往下滚。这里把卡内纵向间距收紧约 17dp（标题行 70px、四宫格上边距 42px、知识点上边距 62px），整卡在首屏内连圆角一起显示完，滚动只用于看「答题卡」。
- **答题卡题号改为左对齐**：原版用 space-between 把 9 个题号均匀铺满整行，这里改成从左边起按固定列距排列（列距 36dp，即圆心间距 68dp），末行不足 9 个时就左边收尾、右侧留白。
- **原版「AI学习建议」卡（浅蓝渐变 + 斜切藏青标签 + 深紫胶囊按钮）已按要求去掉**，报告页只保留「考试情况」「答题卡」两张卡；原版截图仍留在 `shots/03-成绩报告-AI学习建议.png` 作为对照存证，不参与复刻。
