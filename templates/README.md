# 导入模板

这个目录里的文件**都能直接导入 App**，内容是最小可用的 5 道题（单选 / 多选 / 一篇材料带 3 道小题）。
把内容换成你自己的题，就是一份自己的试卷。

**统一只有 Excel 一种格式**；图片等多媒体资源走试卷包（zip）。

## 有什么

| 文件 | 用途 |
|---|---|
| `试卷模板.xlsx` | 在 Excel / WPS 里填，最直观。两张表：「试卷」填数据（一行一题），「使用说明」是内置指南，导入时自动跳过 |
| `答案模板.xlsx` | 补答案用：`题号 / 答案 / 解析` |
| `解析模板.xlsx` | **单独补解析**用：`题号 / 解析`——只更新解析，不改答案 |
| `试卷包模板/` | 试卷包的目录形态：`试卷.xlsx` + `images/chart-01.png` + `README.txt` |
| `试卷包模板.zip` | 上面那个目录压好的包，直接导入体验「图片随包走」 |
| `make_templates.js` | 生成脚本：从 `试卷模板.json` 生成其余全部模板，并回读校验 |
| `试卷模板.json` | 仅作为生成脚本的数据源，**不是**可导入格式（导入只认 Excel） |

`试卷模板.json` 是唯一数据源。改了题目后重跑一次，其余文件一起更新：

```bash
node templates/make_templates.js
# 模板已生成：5 题 → 试卷.xlsx（含使用说明）/ 答案.xlsx / 解析.xlsx / 试卷包
# 回读校验：23/23 通过
```

脚本末尾会按 App 导入器的规则**回读每个产物**（XLSX 共享字符串、zip 条目），
有任何一条不通过会以非零码退出，用于防止模板悄悄坏掉。

## 怎么改成自己的试卷

以 `试卷模板.xlsx` 为例：

1. 删掉示例的 5 行，从第 2 行开始填自己的题；
2. 每行至少要有：**题干** + **选项A–D**（当前只支持选择题）+ **答案**；
3. 多选答案在单元格里直接写 `A,B,D`，不用加引号；
4. **导入时这个文件会成为一个「标题」**（默认取文件名，导入页上就能改），文件里的卷挂在它下面；
   单表文件只有一份卷，卷名跟标题走，所以「试卷模板」→ 改成你的试卷名更直观；
5. 导入后预览页还能改名、设限时；列表里长按标题可随时重命名。

> 多套卷想一次导完：**在同一个 xlsx 里按套分工作表**（sheet 名即卷名），每个工作表各成一份试卷，它们同属这一个标题；
> 懒得拆表就在表里加一列「试卷」按行分组。多个文件也能一次全选，一个文件一个标题。
> 两种拆法见 [02 试卷格式规范](../docs/02-试卷格式规范.md#一份-excel-放多份试卷)。

| 列 | 必填 | 说明 |
|---|---|---|
| 题型 | 否 | 留空按单选；多选/判断/不定项要写清楚 |
| 题干 | **是** | 空题干的行会被跳过 |
| 材料 | 否 | 多行也行，支持 Markdown 表格、`![图](路径)`、`:::chart`；**同材料的题要连续、且材料逐行重复填** |
| 图片 | 否 | 题图地址（本地路径 / base64 / 试卷包内相对路径），多张用 `\|` 分隔；导入时前置到材料顶部显示 |
| 选项A–D | **是** | 最多到 H，空的不填即可 |
| 答案 | 否 | 不填 = 待补答案，之后能补 |
| 解析 | 否 | 不填 = 待补解析，之后能用「解析文件」单独补 |
| 知识点 / 难度 / 地区 / 科目 / 来源 / 年份 / 分值 | 否 | 影响报告与筛选，不影响判题 |

## 答案与解析可以分开导

模板里**答案列和解析列都可以整列留空**，先把题目导进来开练，之后分开补：

| 时机 | 怎么做 |
|---|---|
| 补答案 | 导入 `答案模板.xlsx`（`题号,答案`），或成绩报告里逐题补录 |
| 补解析 | 导入 `解析模板.xlsx`（`题号,解析`）——**只更新解析，不改答案**；「导入文件」入口会自动认出解析文件 |
| 一起补 | 答案模板本身就带解析列，一次导两样 |

细节见 [docs/04-答案后补](../docs/04-答案后补.md)。

完整字段与别名见 [docs/02-试卷格式规范](../docs/02-试卷格式规范.md)。

## 一篇材料配多道小题怎么填

卷面是「大类题型 → 材料 → 题目」三级，但它不是单独的表结构，而是从 `科目` / `材料` 两列**连续重复**里派生的。
所以一组材料题要写成这样（模板里第 3–5 行就是）：

| 行 | 科目 | 材料 | 题干 |
|---|---|---|---|
| 3 | 行测·资料分析 | 整段材料（含表格） | 同比增加多少亿元？ |
| 4 | 行测·资料分析 | **同一段材料，原样再写一遍** | 上年同期约多少亿元？ |
| 5 | 行测·资料分析 | **同一段材料，原样再写一遍** | 占比约多少？ |

* **同材料的题必须挨着**：中间插了别的题，就会被拆成两个材料组，材料在卷面上重复显示；
* **材料逐行重复**：留空 = 这道题不带材料，会被当成独立题（不会自动沿用上一行）；
* **科目逐行填**：留空会并进「未分类」段，那一段不出大类说明卡。

导入预览页会针对这三条做一次「结构体检」，不合格会以整卷级提示列出来（不影响导入）。

完整规则见 [docs/02-试卷格式规范](../docs/02-试卷格式规范.md) 的「卷面结构」一节。

## 常见坑

* **Excel 合并单元格**：不会展开，只有左上角有值，长文本别跨行合并。
* **同一个表头出现两次**：只取靠前那列。
* **试卷包里的 Excel 没命名好**：叫 `试卷.xlsx` 最稳，别放到二级目录里。
* **材料带图又发给别人**：单个 xlsx 带不了图（本地路径在别人手机上不存在）——做成试卷包，图片随包走。

## 备注

* 试卷包模板里的图 `images/chart-01.png` 是脚本生成的占位图（无语义），换成你自己的图即可，记得同步改 Excel 里的引用。
* 想凑一份「有内容的完整示例」看效果，用 App 导入页的「载入示例」，或 `sample/` 下的行测 11 题与资料分析试卷包。
