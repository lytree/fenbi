# 导入模板

这个目录里的文件**都能直接导入 App**，内容是最小可用的 5 道题（单选 / 多选 / 一篇材料带 3 道小题）。
把内容换成你自己的题，就是一份自己的题库。

## 有什么

| 文件 | 用途 |
|---|---|
| `题库模板.xlsx` | 在 Excel / WPS 里填，最直观。表头别改，一行一题 |
| `题库模板.csv` | 同样的表头，纯文本，方便脚本生成或 diff |
| `题库模板.json` | 字段最全，选项/答案用结构化写法 |
| `题库模板.txt` | 一行一题手打，题号 + A/B/C/D + `答案：` 前缀 |
| `答案模板.csv` | 补答案用：`题号,答案,解析` |
| `答案模板.txt` | 补答案最省事的写法：`1.A` 一行一题 |
| `题库包模板/` | 题库包的目录形态：`qbank.json` + `images/chart-01.png` + `README.txt` |
| `题库包模板.zip` | 上面那个目录压好的包，直接导入体验「图片随包走」 |
| `make_templates.js` | 生成脚本：从 `题库模板.json` 生成其余全部模板，并回读校验 |

`题库模板.json` 是唯一数据源。改了题目后重跑一次，其余文件一起更新：

```bash
node templates/make_templates.js
# 模板已生成：5 题 → CSV / TXT / XLSX / 答案 ×2 / 题库包
# 回读校验：29/29 通过
```

脚本末尾会按 App 导入器的规则**回读每个产物**（表头别名、TXT 题号切块、XLSX 共享字符串、zip 条目），
有任何一条不通过对以非零码退出，用于防止模板悄悄坏掉。

## 怎么改成自己的题库

以 `题库模板.xlsx` 为例：

1. 删掉示例的 5 行，从第 2 行开始填自己的题；
2. 每行至少要有：**题干** + **选项A–D**（当前只支持选择题）+ **答案**；
3. 多选答案写成 `A,B,D`（在 Excel 单元格里不用加引号；导出 CSV 时脚本会自动加）；
4. 试卷名就是文件名，「题库模板」→ 改成你的试卷名更直观；
5. 导入后预览页还能改名、设限时。

| 列 | 必填 | 说明 |
|---|---|---|
| 题型 | 否 | 留空按单选；多选/判断/不定项要写清楚 |
| 题干 | **是** | 空题干的行会被跳过 |
| 材料 | 否 | 多行也行，支持 Markdown 表格、`![图](路径)`、`:::chart`；**同材料的题要连续、且材料逐行重复填** |
| 选项A–D | **是** | 最多到 H，空的不填即可 |
| 答案 | 否 | 不填 = 待补答案，之后能补 |
| 解析 / 知识点 / 难度 / 地区 / 科目 / 来源 / 年份 / 分值 | 否 | 影响报告与筛选，不影响判题 |

完整字段与别名见 [docs/02-题库格式规范](../docs/02-题库格式规范.md)。

## 一篇材料配多道小题怎么填

卷面是「大类题型 → 材料 → 题目」三级，但它不是单独的表结构，而是从 `科目` / `材料` 两列**连续重复**里派生的。
所以一组材料题要写成这样（模板里第 3–5 行就是）：

| 行 | 科目 | 材料 | 题干 |
|---|---|---|---|
| 3 | 行测·资料分析 | 整段材料（含表格） | 同比增加多少亿元？ |
| 4 | 行测·资料分析 | **同一段材料，原样再写一遍** | 上年同期约多少亿元？ |
| 5 | 行测·资料分析 | **同一段材料，原样再写一遍** | 占比约多少？ |

* **同材料的题必须挨着**：中间插了别的题，就会被拆成两个材料组，材料在卷面上重复显示；
* **材料逐行重复**：留空 = 这道题不带材料，会被当成独立题（不会自动沿用上一行）；
* **科目逐行填**：留空会并进「未分类」段，那一段不出大类说明卡。

导入预览页会针对这三条做一次「结构体检」，不合格会以整卷级提示列出来（不影响导入）。
TXT 同理：每个题块都要自己写一遍 `材料：`。

完整规则见 [docs/02-题库格式规范](../docs/02-题库格式规范.md) 的「卷面结构」一节。

## 常见坑

* **多选答案没加引号**：CSV 里写 `A,B,D` 会被拆成三列，必须写 `"A,B,D"`（Excel 直接导入不受影响）。
* **TXT 里材料/解析以「数字 + 点」开头**（如 `2.5亿元`）：会被当成新题号，整份文件从那里被切断。
* **Excel 合并单元格**：不会展开，只有左上角有值，长文本别跨行合并。
* **同一个表头出现两次**：只取靠前那列。
* **题库包主数据没命名**：叫 `qbank.json` 最稳，别放到二级目录里。
